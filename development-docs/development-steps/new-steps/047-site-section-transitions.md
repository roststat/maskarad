# 047 — Смысловые и визуальные переходы на всём сайте

Дата предложения: 2026-10-09. Статус: 047-1/2/3 завершены, локальная версия проверена; 047-4 ждёт подтверждения публикации после отказа автоматической проверки. Внедрение по решению владельца «делай» от 2026-10-09. Исходное предложение сохранено ниже; результат и проверки записываются по подшагам.

## Запрос владельца дословно

«https://more-show.ru/about посмотри сайт море шоу, там между блоками есть всякие фразы, может тоже так сделаем? А то у нас просто дырки между блоками получаются»

«предложи решение»

Уточнение масштаба: «Это не только про корпоративную страницу, про весь сайт».

## Предлагаемое решение

Единая система переходов для главной, каталогов, страниц спектаклей, услуг и праздников, контентных хабов и статей. Сокращать избыточные интервалы и выбирать переход по смыслу соседних разделов. Длинная страница получает ориентировочно 2–3 перехода, короткая — один, если он помогает чтению. Число уточняется на макетах. Каталоги сохраняют непрерывность выбора; в статье переход размещается после материала, перед подходящими программами или обращением.

Три варианта:

1. Короткая крупная фраза между этапами выбора: 1–2 строки, винный цвет, существующий шрифт заголовков, небольшая золотистая театральная деталь.
2. Реальная фотография с короткой подписью между описанием и блоком доверия. Просмотр фотографии использует попап 045/046 внутри текущей страницы.
3. Приглашение обсудить праздник перед формой. Кнопка ведёт к форме текущей страницы; контекст программы сохраняется.

Фразы работают в последовательности «выбор → живой опыт → состав и организация → обращение». Подписи к реальным фото описывают видимое событие; новые утверждения об опыте, отзывы и цифры требуют фактуры владельца.

## Примеры для редакционного отбора

| Тип страницы / место | Предложение |
|---|---|
| Главная, перед живыми фотографиями | «Здесь дети становятся участниками сказки» |
| Каталог спектаклей, перед подборкой | «Какую сказку сыграем для ваших детей?» |
| Страница интерактивного спектакля, перед участием детей | «У этой истории есть роли для ваших детей» |
| Услуги, перед дополнениями к программе | «Добавим к празднику яркие детали» |
| День рождения | «Приключение, в центре которого — именинник» |
| Детский сад / школа | «Приключение для всей группы» / «История для вашего класса» |
| Зимние праздники | «Пусть новогодняя сказка оживёт на вашем празднике» |
| Конец полезной статьи | «От идеи — к программе вашего праздника» |
| Перед формой | «Расскажите о празднике — соберём программу под вас» |

Для разных программ текст уточняется по содержанию и интенту страницы. Формулировка не повторяется на каждой границе разделов и не меняется случайно при загрузке. Существующая мини-галерея под hero остаётся самостоятельным коротким доказательством опыта.

## Ритм и оформление

- Сейчас обычный системный интервал задан как `clamp(4.5rem, 8vw, 7.5rem)`: при базовом размере 16 px это 72–120 px; на узком экране — 68 px. Источник: `app/globals.css`, прежний шаг 003-16.
- Предлагаемый диапазон для обычных переходов: 48–72 px на большом экране и 32–40 px на телефоне. Финальные значения выбираются после просмотра плотных каталогов и длинных посадочных.
- Фраза занимает существующий переход; дополнительные большие интервалы сверху и снизу не накапливаются.
- Ориентир для крупной фразы: 40–56 px на большом экране, 24–32 px на телефоне; читабельный контраст и естественный перенос.
- Сохраняем кремовый фон, винную типографику и небольшие золотистые детали «Маскарада». Чередуем текстовые, фотографические и спокойные переходы без текста.
- Служебные и правовые страницы оформляются по их содержанию; рекламные фразы там не нужны.

## Референс

[Страница «Море шоу»](https://more-show.ru/about) просмотрена 2026-10-09: крупная центрированная фраза связывает блок преимуществ с фотографиями, рядом используется небольшой декоративный знак. Заимствуем принцип перехода; тексты, стиль и факты о компании создаём для «Маскарада».

Отправка и автодеплой не выполнялись. Предыдущая опубликованная версия сохраняется. Владельцу предъявлены локальный результат, проверки и скриншот; запрошено подтверждение публикации на сервере.
