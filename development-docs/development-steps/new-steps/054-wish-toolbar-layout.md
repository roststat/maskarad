# 054 — Аккуратная панель под полем пожеланий

2026-10-10. Решение владельца дословно: «сделай кнопку полегче та чтобы она не перекрывала текст может поле с письмом поправь ну или сам реши чтобы это было аккуратнее».

Уточнение владельца дословно: «Слишком большое поле не делай пусть оно расширяется исходя из размера, на старте 4 полосы достаточно».

Ещё одно уточнение: строки «Диктовка запускается по нажатию и может использовать сервис вашего браузера.» и «ИИ правка передаёт только текст пожеланий в OpenAI по нажатию кнопки.» — «это в подсказку не нужно убери». Обе строки удалены из попапа.

Решение: вынести ИИ правку и микрофон в отдельную строку под textarea, сделать ИИ кнопку визуально легче. Начальная высота — четыре строки, поле растёт и сокращается по тексту при вводе, диктовке, ИИ правке и возврате оригинала; пересчитывается при изменении ширины экрана. Поле использует всю ширину для текста; кнопки и статус диктовки находятся вне текста.

| Подшаг | Результат | Проверка | Статус |
|---|---|---|---|
| 054-1 | Панель в потоке, лёгкое оформление, четыре строки и рост | Сборка + сравнение разметки | Завершён локально |
| 054-2 | Локальный просмотр и память | Браузер desktop/mobile, рост/сокращение по тексту + итог | Завершён локально |

Обработчики ИИ правки, диктовки и заявки остаются существующими. Проверка без отправки заявки и запуска микрофона; публикация отдельно.
