# 004 — Машиночитаемые страницы услуг

## Цель

Сделать действующие программы понятнее поисковым системам и автоматическим читателям без обещания несуществующего агентного бронирования.

## Решение владельца

> «Вот это хорошее современная размётка для агентов. Используй  все имеющиеся здесь стандарты»

Источник: приложенный пример HTML с SEO, Open Graph, Schema.org, Markdown alternate, A2A и OpenAPI.

## Подшаги

| Подшаг | Результат | Проверка |
|---|---|---|
| 004-64 Schema.org для программ | На страницах программ есть Service и FAQPage с фактическими данными и ссылкой на форму | Типы + HTML локального сервера |
| 004-65 Markdown alternate | Каждая страница из каталога программ имеет Markdown-версию и ссылку alternate | Сборка + HTTP-заголовки и тело |

## Границы

- Не публиковать выдуманные цены, наличие, бронирование или API для отправки персональных данных.
- A2A Agent Card уместна только при появлении настоящего A2A-агента; файл `/.well-known/agent.json` из примера не является его стандартным адресом.
- OpenAPI `service-desc` уместен после решения о публичном API и его защите.
- Structured data отражает видимое содержимое страниц; выдача в поиске не гарантирована.
