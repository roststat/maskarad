# 080 — Основной домен и старый адрес карты сайта

23 октября 2026. Владелец поручил: «Осталось два полезных улучшения: настроить постоянный переход с `www` на основной домен и направить `/karta.html` прямо на новую карту сайта. делай».

1. 080-1: сверить свежесть и сохранить действующую конфигурацию Nginx перед применением. Подготовить отдельные блоки HTTPS основного домена/www и общий HTTP. Основной домен сохраняет прежнее проксирование; www/HTTP ведут на фиксированный HTTPS non-www с сохранением path/query. Старый `/karta.html` на всех вариантах ведёт непосредственно на `/karta-sayta`. Доказательства: diff и штатный gate.
2. 080-2: отправить код через origin/main; штатный автодеплой, совпадение server HEAD/маркера. Применить только virtual host Маскарада с резервной копией и nginx -t; при ошибке восстановить конфигурацию. Доказательства: серверный gate и валидная конфигурация/успешный reload.
3. 080-3: проверить публичные HTTP/HTTPS, www/non-www, path/query, карту, TLS и неизвестный URL; сверить основной сайт и другие процессы. Записать итог. Доказательства: матрица HTTP-ответов и внешний SEO smoke-test.

Связь: 079 и 025-4. Не закрывает весь 025-4: общая политика всех неизвестных исторических URL не входит в этот пакет. Индексацию Google сразу после релиза не обещать.
