# 051 — Начало страницы при переходах по крошкам и карточкам

2026-10-10. Решение владельца дословно: «Переходы через меню и по логотипу теперь открывают страницу сверху, без обрезанного хиро. //  через меню поправил, осталось что также режет при переходах по хлебным крошкам и через карточки на страницах и».

Расширить поведение 048 на внутренние переходы между страницами: хлебные крошки, карточки главной/каталогов/посадочных/статей, связанные программы и другие навигационные ссылки. Сохранить поведение ссылок с #якорем, внешних ссылок и истории браузера. Контроллер прокрутки должен переживать размонтирование исходной карточки/крошек при переходе.

| Подшаг | Результат | Проверка | Статус |
|---|---|---|---|
| 051-1 | Общий механизм начала страницы и подключение публичных ссылок | Типы/сборка + сверка ссылок | Завершён локально |
| 051-2 | Переходы после прокрутки проверены на desktop/mobile | Браузер: крошки, карточки, меню и якорь + FAQ | Завершён локально |
| 051-3 | Память и итог обновлены, локальная версия доступна | Отчёт/протокол + локальный просмотр | Завершён локально |

Работа локально, публикация пакета отдельно. Отступы и SEO-даты не менять.
