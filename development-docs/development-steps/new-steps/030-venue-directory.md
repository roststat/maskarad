# 030 — Каталог ресторанов, лофтов и площадок

Дата плана: 9 октября 2026 года, Москва.

Состояние на дату создания плана: **запланировано; подшаги не выполнены**. Текущее состояние отмечается в [current-steps.md](../current-steps.md).

Приоритет: P2.

## Цель и границы

Найти место, подходящее детскому театральному празднику, понять условия и перейти к совместимой программе.

Пилот 20–25 карточек либо меньше по доступным фактам. Категории и подборки входят в общий лимит 4–8 новых таких URL; расширение после результата.

## Входные данные и зависимости

024, компоненты/политики 025, проверенные источники площадок; базовые программные ограничения 026.

Источники: Официальные сведения/проверенный опыт по местам, условия внешних артистов, помещения, стоимость с составом, фотографии и дата проверки.

Роли: Ответственный за данные — назначается до сбора; агент — схема, интерфейс, проверки; театр/владелец — подтверждённые отношения и право публикации.

Перед работой сверить фактическую доступность входов. Ожидание источника блокирует зависимый подшаг; доступную независимую часть продолжаем, состояние фиксируем без объявления полного завершения.

## Подшаги

| Подшаг | Работа | Результат одной строкой | Два подтверждения |
|---|---|---|---|
| 030-1 | Выбрать схему данных и доступный способ редакционного обновления | У места есть постоянный ID/филиал, поля стоимости, ограничений, источника и свежести | Схема с типами/обязательными полями + проверка на трёх разных типах реальных мест |
| 030-2 | Определить источники, статусы и правила обслуживания | Неизвестные условия явно видны; каждой карточке назначена следующая сверка | Реестр источников/ответственных + содержательная проверка условия внешних артистов и бюджета |
| 030-3 | Собрать и проверить пилот, исключить дубли филиалов | Есть первый набор пригодных к выпуску карточек с оригинальным описанием | Проверка ID/адресов/полноты + сверка с источниками и опытом театра |
| 030-4 | Создать карточки, категории и связи с программами | Публичная карточка объясняет пригодность места и стоимость с составом | Типы/сборка/HTTP + mobile/desktop и сверка подтверждённых полей |
| 030-5 | Добавить первые фильтры по месту, группе, бюджету и условиям артистов | Фильтрация учитывает фактические ограничения и неизвестное | Проверка наборов данных + браузерные сценарии, пустой результат и сброс фильтров |
| 030-6 | Реализовать политику индексации категорий, объектов и параметров | Полезные URL доступны, комбинации/сортировки не создают бесконтрольную массу | Обход ссылок/robots/canonical/noindex + проверка поискового представления доступных адресов |
| 030-7 | Выпустить пилот и назначить обслуживание данных | Каталог работает публично, известны ответственность и сроки следующей сверки | Штатные проверки + публичные карточки/фильтры/актуальность и доступные события |

## Условие закрытия

Есть рабочий проверенный пилот с карточками, категориями, фильтрами, программными связями и ответственным за актуальность. Количество без подтверждённых условий не закрывает шаг.

## Ограничения и решения

Не выдумывать наличие свободной даты и опыт выступления. Для цены нужны единица расчёта, состав, доплаты и дата. Сначала модерируемый формат; новая БД/CMS только по установленной необходимости и отдельному решению.
