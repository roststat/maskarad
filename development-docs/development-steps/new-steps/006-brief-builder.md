# 006 — Бриф праздника как самостоятельная польза

## Цель

Дать посетителю возможность составить и сохранить PDF-бриф без обязательной заявки. Быстрая форма остаётся с именем и телефоном; помощник открывается из неё только по нажатию. Отправка брифа театру — отдельный добровольный шаг после готового документа.

## Подшаги

1. Добавить общий вход в помощника из всех форм, сохранив вход через маску в шапке. Доказательство: оба входа открывают одно окно и не дублируют состояние.
2. Разделить создание брифа, PDF и предложение отправки на последовательные состояния. Доказательство: PDF можно скачать без имени и телефона; поля контакта появляются только после отдельного выбора.
3. Уточнить тексты CTA и мобильную компоновку, проверить сборку и сценарии в браузере. Доказательство: TypeScript и production-сборка проходят, desktop/mobile показывают оба пути без наложений.

## Границы

- Быстрая заявка по имени и телефону остаётся доступной отдельно.
- PDF создаётся в браузере; отправка в `/api/leads` происходит только по явному действию посетителя.
- Секреты OpenAI и канал получения заявок не меняются в этом шаге.
