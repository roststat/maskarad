# 004 — FAQ на всех URL sitemap

Решение владельца 2026-10-09: «Все 122 страницы» в ответ на вопрос о масштабе добавления примерно пяти видимых вопросов и ответов с JSON-LD.

## Подшаги

1. Аудировать публичные примеры и состав sitemap. Результат: зафиксировано исходное количество FAQ и 122 URL.
2. Добавить по пять видимых ответов и `FAQPage` на каждый URL из sitemap, опираясь на существующий контент. Результат: HTML и JSON-LD используют один источник данных.
3. Встроить сквозную проверку в `seo:predeploy`. Результат: production HTML всех 122 URL проходит сверку количества и текста.

Отдельный цикл 009 остается календарём содержательных обновлений: этот шаг не меняет даты публикации страниц и не считает шаблонное дополнение FAQ подтверждённой актуализацией всей страницы.
