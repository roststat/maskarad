# 071 — Убрать общий фотоблок материалов

14 октября 2026. Поручение владельца: «что за визуальные опоры, этот заголовок сломает сео убирай блок».

| Подшаг | Результат | Доказательства |
|---|---|---|
| 071-1 Шаблон | Общий блок «Фото / Визуальные опоры страницы» удалён из материалов; главное фото сохранено | исходный код + собранный HTML |
| 071-2 Проверка | В зимней подборке нет шаблонного H2, а структура заголовков и SEO-разметка целы | браузер + полный SEO gate |
| 071-3 Публикация | Исправленный шаблон работает на основном домене | серверный HEAD/маркер + публичный HTML/браузер |

Удаление касается шаблона всех материалов, где блок выводился. Исторические данные галерей пока остаются в `app/content-data.ts`, но не показываются; их можно использовать только после отдельного решения об осмысленном фотоблоке.
