# 043 — Компактная галерея под первым экраном

Решение владельца 2026-10-09 дословно: «Добавь фотографии мелкой галереей с переходм в основную галереею под хиро блок на каждой странице, только разные фотки делай на разных страницах по три четыре фотки».

| Подшаг | Результат | Доказательства |
|---|---|---|
| 043-1 | Общая компактная галерея с устойчивой подборкой 3–4 фото для URL | Исходник выбора + реестр 102 фото |
| 043-2 | Галерея сразу под hero во всех шаблонах страниц с первым экраном | Исходники шаблонов + сборка/покрытие sitemap |
| 043-3 | Проверка различия подборок, ссылки и desktop/mobile | HTML всех URL + браузер |

Область: главная, корпоративная, посадочные, каталоги, хабы и статьи; страницы без hero (служебные документы, API, Markdown) в этот блок не входят. Используются предоставленные фото 042, тематические кадры предпочтительны. Подборка стабильна при перезагрузке, не повторяет фото своего первого экрана. Выход ведёт к полной галерее `/foto-video`. Работа локальная, выпуск и календарь 009 отдельно.
