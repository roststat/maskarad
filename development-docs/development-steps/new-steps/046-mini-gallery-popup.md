# 046 — Попап для фотографий под hero

Решение владельца 2026-10-09 дословно: «Фотографии под зиро блоком тоже уводят человека с нужной страницы когда по клику редиректят на галерею. Нужно их также открывать попапом.»

Последнее решение заменяет прежний переход миниатюр в полную галерею 043/045. Самостоятельная текстовая ссылка «Все фотографии» остаётся переходом. Фото открывает существующий просмотрщик 045 на текущей странице; стрелки, клавиатура и горизонтальный жест листают три/четыре кадра конкретной подборки. После закрытия URL, позиция страницы и фокус сохраняются.

| Подшаг | Результат | Доказательства |
|---|---|---|
| 046-1 | Миниатюры используют PhotoOpenButton, стили сетки сохранены | Исходники + сборка/HTML 122 URL |
| 046-2 | Проверены открытие нужного кадра, листание и возврат на desktop/mobile | HTML покрытия + браузер/скриншоты |
| 046-3 | Исправление опубликовано и память обновлена | Серверный HEAD/маркер/gate + публичный браузер |

Разные устойчивые наборы 043 не пересчитываются. Редакционные даты и счётчик 009 не меняются: исправление поведения галереи.
