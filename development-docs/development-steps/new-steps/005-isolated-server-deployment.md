# 005 — Изолированное размещение на сервере

## Цель

Разместить сайт «Маскарад» на сервере, где уже работают Fractera/«Автозабота» и Maxflok, не меняя их каталоги, процессы, порты или Nginx-конфигурации.

## Границы

- Не использовать `/opt/fractera/app` и порты Fractera `3000–3002`.
- Использовать отдельный контур `/opt/maskarad/app`, порт `3200` и процесс `maskarad-site`.
- Не выпускать TLS-сертификат и не менять публичный Nginx, пока DNS `maskarad-teatr.ru` не указывает на этот сервер.
- Не переносить `.env.local`, архив старого сайта, git-метаданные или чужие секреты в поставку приложения.

## Подшаги

1. Зафиксировать инвентаризацию сервера и границы изоляции.
2. Доставить production-код в `/opt/maskarad/app`, установить зависимости и собрать сайт.
3. Запустить `maskarad-site` на `127.0.0.1:3200`, проверить процесс и HTTP-ответ локально на сервере.
4. После изменения DNS добавить отдельный Nginx-виртуальный хост, выпустить TLS, проверить публичные 308, sitemap, robots и основные URL.

## Условие закрытия

Сайт отвечает по `https://maskarad-teatr.ru`, не затрагивая Fractera и Maxflok; Nginx, PM2 и DNS проверены раздельно, а SEO pre-deploy и внешний smoke-test пройдены.
