# 004 — SEO-портал и контент-машина

## Цель

Перестроить сайт «Маскарад» из набора посадочных в масштабируемый портал по организации детских праздников, где SEO, UX, медиа, кейсы, статьи и рекламные места заранее встроены в архитектуру.

## Почему сейчас

Владелец подтвердил новый фокус:

> «Нам надо сделать сео машину, чтобы все было идеально сделано.»

> «Будем также делать статьи аля кейсы и наработывать страничную массу...»

> «хочется также чтобы были места под рекламу для яндекс РСЯ и другие баннеры.»

## Подшаги

| Подшаг | Результат | Доказательство |
|---|---|---|
| 004-1 Структура SEO-портала | Зафиксирована карта типов страниц, шаблон SEO-страницы, заголовки, хлебные крошки, schema, медиа, рекламные слоты | Есть отчет `development-docs/reports/004-seo-portal-structure-plan.md` |
| 004-2 Базовые SEO-компоненты | В коде есть `Breadcrumbs`, JSON-LD, quick facts, gallery, FAQ, related links, ad slot | `npm run build`; HTML содержит breadcrumbs/schema |
| 004-3 Аудиторные страницы | Есть `/dlya-detey`, `/dlya-vzroslyh`, `/dlya-biznesa`; шапка ведет на них | `curl -I` возвращает `200 OK`; sitemap содержит страницы |
| 004-4 Каркас контент-разделов | Есть `/stati`, `/kejsy`, `/podboroki` с листингами и первыми материалами | `npm run build`; страницы есть в sitemap |
| 004-5 Первый пакет контента | Добавлены 3-5 материалов: кейс, статья, подборка, возрастная страница | `npm run build`; внутренняя перелинковка работает |
| 004-6 Рекламные зоны | Компонент рекламного слота встроен в шаблоны без вреда UX | Мобильная проверка без перекрытия CTA и горизонтального скролла |

## Правила качества

- Не делать страницы ради количества без уникального интента.
- Не копировать старые тексты: использовать как сырье и переписывать.
- Каждая страница должна иметь понятный H1, intro, блоки H2, фото/медиа, внутренние ссылки и CTA.
- Хлебные крошки обязательны для вложенных страниц.
- Реклама не должна быть на первом экране и не должна ломать мобильный путь к заявке.
- Кейсы предпочтительнее абстрактных статей, если есть фото и реальная история.

## Первая реализация

Начать с 004-2 и 004-3:

1. Добавить хлебные крошки и JSON-LD.
2. Расширить шаблон посадочных под факты, галерею, FAQ, связанные ссылки и рекламные слоты.
3. Создать `/dlya-detey`, `/dlya-vzroslyh`, `/dlya-biznesa`.
4. Перепривязать верхнюю навигацию на эти страницы.
5. Проверить сборку и локальные страницы.
