# 004-54 — Посадочные сказочных форматов

## Результат

Добавлены отдельные посадочные:

- `/spektakli/skazochnyy-balaganchik`;
- `/spektakli/ivan-da-marya`;
- `/spektakli/volshebnaya-feya`.

Для каждой архивной темы сформулирован современный сценарий выбора интерактивной программы. Архивные изображения помечены как иллюстрации, а не как подтверждение актуального репертуара.

Три старых URL теперь ведут постоянным точным редиректом на свои тематические страницы вместо общего каталога спектаклей.

## Доказательства

- `npm run seo:predeploy` прошел: покрытие 163 внутренних старых URL, аудит 179 правил, alt, TypeScript и production-сборка 111 статических страниц.
- `npm run seo:migration-relevance` показал 49 широких тематических назначений вместо 52; URL, покрытых только catch-all-правилом, нет.
