## Результат

Система подключена к главной, каталогам, посадочным спектаклей/услуг/праздников, странице театра, фото, цен, отзывов, хабам и материалам. Заголовок хабов «Страницы для роста трафика» заменён на понятный посетителю «Идеи и советы для вашего праздника».
