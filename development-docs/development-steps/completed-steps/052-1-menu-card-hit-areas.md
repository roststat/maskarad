# 052-1 — Ссылка раздела занимает карточку меню

2026-10-10. В CSS заголовочная ссылка получила область на всю карточку. Ссылки отдельных пунктов находятся поверх неё и имеют ширину своего названия с сохранённым вертикальным отступом. Нет вложенных ссылок, новых кнопок или обработчиков перехода на section. Все три аудитории используют общие стили.

Доказательства: `npm run build` прошёл с проверкой TypeScript; браузерная проверка elementFromPoint на свободном месте рядом с первым пунктом возвращает group.href для всех 12 карточек desktop. Ссылка первого пункта «Праздников» имеет ширину 103 px при ширине карточки 276 px.

Результат: свободное место карточки принадлежит ссылке раздела, названия пунктов — своим ссылкам. Завершён локально.
