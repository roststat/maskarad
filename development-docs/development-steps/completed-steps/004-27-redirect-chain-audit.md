# Подшаг 004-27 — аудит цепочек редиректов

## Результат

Добавлена команда `npm run seo:redirect-audit`. Она извлекает правила из `next.config.ts` и проверяет, не ведёт ли destination одного редиректа в другой redirect source и не образуется ли цикл.

## Доказательство

Проверены 179 правил: цепочек и циклов редиректов не обнаружено.

## Следующий внешний контроль

После открытия Vercel preview нужно проверить фактические HTTP-статусы и `Location` для старых URL. Статический аудит не заменяет сетевую проверку production-конфигурации.
