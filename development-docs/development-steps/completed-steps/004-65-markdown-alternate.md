# 004-65 — Markdown-версии посадочных

Для 64 посадочных создан статически собираемый маршрут `/markdown/...`; в HTML добавлена ссылка `rel="alternate" type="text/markdown"`. Markdown содержит вводный текст, факты, основные разделы, состав программы, FAQ и публичный путь к форме. Ответ ссылается на HTML-каноникал через HTTP `Link`.

Доказательства: сборка создала 64 маршрута Markdown; локальный запрос `/markdown/spektakli/peppi-dlinnyy-chulok` вернул `200`, `Content-Type: text/markdown` и содержимое программы, а HTML-ссылка alternate указывает на этот маршрут.
