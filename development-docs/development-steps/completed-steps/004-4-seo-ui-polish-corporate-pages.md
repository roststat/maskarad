# 004-4 — SEO/UI-полировка корпоративных страниц

## Задача

После запуска контент-машины проверить новые хабы и корпоративные материалы: убрать чрезмерно крупные hero-заголовки, добавить недостающую SEO-обвязку на кастомную страницу и убедиться, что страницы не ломают интерфейс.

## Что сделано

- Кастомная страница `/prazdniki/korporativnyy-novogodniy-prazdnik` получила:
  - визуальные хлебные крошки;
  - `WebPage` schema;
  - `BreadcrumbList` schema;
  - рекламный слот после proof-блока.
- Для кастомной страницы добавлена русская метка хлебной крошки `Корпоративный новогодний праздник`.
- Уменьшен и выровнен масштаб hero-заголовков:
  - общие hero и section hero стали компактнее;
  - article hero стал компактнее;
  - новогодний hero стал компактнее;
  - мобильный верхний предел H1 снижен.
- Для hero с медиа текстовой колонке дано больше места, чтобы длинные русские заголовки меньше дробились по строкам.

## Доказательства

- `npm run build` прошел успешно.
- Количество статических страниц осталось `53`.
- Локальный сервер `http://localhost:4311` перезапущен на свежую сборку.
- Браузерная проверка `1280×720` показала:
  - `/dlya-biznesa`: H1 снизился до `184px`, горизонтального скролла нет, есть `WebPage`, `BreadcrumbList`, рекламный слот;
  - `/prazdniki/korporativnyy-novogodniy-prazdnik`: H1 `165px`, горизонтального скролла нет, есть `WebPage`, `BreadcrumbList`, рекламный слот;
  - хлебные крошки корпоративной страницы показывают `Главная / Детские праздники / Корпоративный новогодний праздник`;
  - `/stati` и `/stati/korporativnaya-elka-dlya-detey-sotrudnikov` не имеют горизонтального скролла и сохраняют SEO-разметку.

## Следствие

Корпоративный маршрут стал ближе к единому SEO-шаблону портала. Следующий подшаг — пройти мобильный вид ключевых новых страниц в реальном mobile viewport и затем расширять контент-модель под галереи, авторские заметки и блоки выбора.
