# 004-20 — тематическая навигация хабов SEO-портала

Дата: 2026-10-04

## Что сделано

Хабы `/stati` и `/podboroki` получили блок `Быстрый выбор`, который группирует материалы не общей длинной лентой, а по понятным пользовательским интентам.

Для `/stati` добавлены группы:

- по площадке;
- по задаче;
- по сезону и улице.

Для `/podboroki` добавлены группы:

- по возрасту;
- по формату;
- по событию.

`/kejsy` намеренно не получил этот блок, потому что в нем пока мало материалов и лишний слой навигации только утяжелил бы страницу.

## Доказательства

- `npm run build` прошел успешно; Next.js сгенерировал `84/84` статических страниц.
- HTML `/stati` содержит `hub-groups`, группы `По площадке`, `По задаче`, `По сезону и улице` и ссылки на материалы.
- HTML `/podboroki` содержит `hub-groups`, группы `По возрасту`, `По формату`, `По событию` и ссылки на подборки.
- HTML `/kejsy` не содержит `hub-groups`.
- CDP-проверка viewport `390×844` для `/stati`, `/podboroki`, `/kejsy` показала `scrollWidth=390`, `bodyScrollWidth=390`, `hasHorizontal=false`.

## Что дальше

Следующий полезный блок — добавить `ItemList` schema для хабов SEO-портала, чтобы поисковик явно видел список материалов и порядок ключевых ссылок на `/stati`, `/podboroki` и позже `/kejsy`.
