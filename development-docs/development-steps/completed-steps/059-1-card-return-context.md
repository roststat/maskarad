# 059-1 — Контекст только из карточек

Явный `returnFromCard` добавлен в общие карточки каталогов/групп спектаклей, тематические подборки, связанные карточки, карточки главной и корпоративные программы. Меню, крошки, логотип и обычные ссылки не создают возврат. Родительский fallback удалён, видимая подпись только «Назад»; оформление 058 сохранено.

Новый ключ истории не принимает старые широкие пути 057. Возврат расходуется один раз; источник получает состояние без следующего возврата. Израсходованные идентификаторы сохраняются в сессии вкладки, чтобы история/обновление не возрождали кнопку. Новый переход из карточки заменяет прежний контекст. Якоря и восстановление позиции сохраняются.

Доказательство: `npm run seo:predeploy` — типы, 198 страниц, FAQ 122/122, миграция/редиректы/alt прошли; `git diff --check` чистый. Браузерное доказательство — 059-2.
