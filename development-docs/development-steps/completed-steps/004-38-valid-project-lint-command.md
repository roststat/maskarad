# Подшаг 004-38 — рабочая lint-команда проекта

## Результат

Команда `npm run lint` переведена с удалённого из Next.js `next lint` на `tsc --noEmit`. В текущем проекте отдельный ESLint-конфиг и зависимость не подключены, поэтому команда честно выполняет доступную строгую проверку TypeScript.

## Доказательство

`npm run lint` проходит без ошибок и включён в общий `npm run seo:predeploy` перед production-сборкой.
