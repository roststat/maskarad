# Подшаг 004-25 — проверка доступности Vercel preview

## Результат

SEO smoke-test получил предварительную проверку доступности preview. Если Vercel возвращает `401/403`, редирект на авторизацию или страницу Deployment Protection, проверка останавливается с одной понятной причиной.

## Зачем

Закрытый preview нельзя честно проверять как публичный сайт: вместо `robots.txt`, sitemap и HTML страниц тест получает страницу авторизации. Раньше это порождало серию вторичных ошибок про canonical и редиректы.

## Доказательства

- локальный `npm run seo:prelaunch` проходит полный набор проверок;
- закрытый внешний preview завершается сообщением о необходимости открыть доступ к Vercel preview, а не списком ложных SEO-ошибок.

## Ограничение

Доступ к настройкам Vercel Deployment Protection не менялся. Перед production-проверкой владелец должен сделать preview публичным или предоставить штатный способ доступа без помещения секретов в репозиторий.
