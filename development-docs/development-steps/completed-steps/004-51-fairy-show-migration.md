# 004-51 — Посадочные сказочных спектаклей

## Результат

Добавлены отдельные посадочные:

- `/spektakli/alladin-i-zhasmin`;
- `/spektakli/neznaika-v-tsvetochnom-gorode`;
- `/spektakli/piter-pen`.

На них направлены шесть старых URL: по два варианта пути для каждого спектакля. Описания построены как современные сценарии выбора формата, а архивные кадры помечены как иллюстрации, не как фотографии конкретной постановки.

## Доказательства

- `npm run seo:predeploy` прошел: покрытие 163 внутренних старых URL, аудит 179 правил, alt, TypeScript и production-сборка 102 статических страниц.
- `npm run seo:migration-relevance` показал 58 широких тематических назначений вместо 64; URL, покрытых только catch-all-правилом, нет.
