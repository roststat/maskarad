# 008.5 — Расширенный каталог спектаклей

На странице `/spektakli` добавлены все 35 отдельных программ из текущей базы посадочных страниц. Каталог разделён на группы «Классика», «Приключения», «Сказки», «Персонажи» и «Новый год». Существующие URL карточек не менялись.

Доказательства: локальный браузер показывает пять групп и счётчики 6 + 7 + 8 + 10 + 4 = 35 программ; `npm run lint`, `npm run build` и `git diff --check` прошли.
