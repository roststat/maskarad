# 057-2 — Проверка путей и восстановления позиции

Завершён 10 октября 2026.

Результат: в локальном браузере проверены реальный источник, прямой заход, крошки, карточки, якорь, обновление и обычные переходы сверху.

## Доказательства

- `/uslugi` → аквагрим → возврат: исходное и восстановленное `scrollY=1311`; карточка вновь видна. После якоря `#zayavka` и обновления страницы этот возврат сохранён. Финальная сборка повторно дала `1311`, ошибок в консоли свежего окна нет.
- `/spektakli` → «Новогодний экспресс» → якорь заявки → возврат: каталог открыт с `scrollY=10424`, карточка видна; кнопка закреплена под шапкой.
- Прямой заход на «Новогодний экспресс»: ссылка ведёт в `/spektakli`, а не во внешний источник.
- Корпоративная ёлка → крошка «Детские праздники»: появляется «Назад: Корпоративный новогодний праздник», возврат ведёт на корпоративную страницу.
- Корпоративная ёлка → карточка «Новогодний экспресс»: кнопка возвращает именно к корпоративной странице, `scrollY=7120.5`, карточка видна.
- Корпоративная ёлка → мини-галерея «Все фотографии»: межстраничный якорь открыл галерею, контекст сохранён; возврат восстановил исходный участок `scrollY=884.5`.
- Browser back/forward оставляют доступным возврат к услугам. Логотип после якоря и пункт меню после прокрутки в финальной сборке дают `scrollY=0`.
- При глубокой прокрутке строка остаётся на `top=105.59375`, высота 48 px, кнопка 44 px. Сборка и локальный SEO smoke-test 12/12 прошли.

## Ограничение проверки

Проверен настольный viewport 1280×720. Запрос мобильного размера через инструмент браузера не изменил фактический viewport (остался 1280×720), включая новое окно; мобильная браузерная проверка не заявляется выполненной. В CSS сохранены адаптивная ширина, сокращение длинной подписи, горизонтальная прокрутка крошек и область нажатия 44 px; временный override снят.

При проверке найден и исправлен дополнительный сдвиг 32 px после якоря и перехода по логотипу: окончательное начало/восстановление позиции повторяется после готовности разметки и отступа крошек. Действие пользователя прекращает отложенную коррекцию.
