# 004-6 — расширение модели SEO-материалов

## Задача

Расширить контент-машину так, чтобы материалы могли быть не просто текстовыми страницами, а полноценными SEO-посадочными внутри портала: с авторскими заметками, галереями, блоками следующего выбора и точными местами под рекламу.

## Что сделано

- Модель `ContentPage` расширена новыми необязательными блоками:
  - `authorNote` для редакторской или практической пометки;
  - `gallery` для визуального усиления материала;
  - `nextSteps` для внутренней перелинковки на следующий выбор пользователя;
  - `adSlots` для настройки рекламных мест на уровне конкретного материала.
- Шаблон материала в `app/[...slug]/page.tsx` теперь выводит:
  - авторскую заметку;
  - галерею с изображениями;
  - середину страницы под рекламный слот;
  - блок `Что выбрать дальше`.
- Обогащены два материала:
  - `/podboroki/prazdniki-dlya-detey-3-4-goda`;
  - `/stati/korporativnaya-elka-dlya-detey-sotrudnikov`.
- Добавлены CSS-правила для новых блоков и мобильное схлопывание галерей/следующих шагов.

## Доказательства

- `npm run build` прошел успешно.
- Локальный production-preview перезапущен на `http://localhost:4311`.
- `curl -I http://127.0.0.1:4311/stati/korporativnaya-elka-dlya-detey-sotrudnikov` вернул `200 OK`.
- `curl -I http://127.0.0.1:4311/podboroki/prazdniki-dlya-detey-3-4-goda` вернул `200 OK`.
- HTML статьи про корпоративную елку содержит `Для согласования с HR`, `article-gallery`, `ad-mid-content-page`, `article-next` и метку `РСЯ / корпоративный баннер`.
- HTML подборки 3-4 лет содержит `Редакторская пометка`, `article-gallery`, `ad-mid-content-page`, `article-next`, `Следующий шаг по задаче` и метку `Сезонное предложение`.

## Следствие

Каркас SEO-портала стал пригоден для ежедневного выпуска материалов: каждый материал может накапливать текстовую массу, фото, внутренние переходы и рекламные места без отдельной ручной верстки.
