# 004-13 — мобильная проверка после сценарно-площадочного пакета

## Задача

Проверить мобильный viewport после добавления пакета про ТЦ, парк, класс, праздник для девочки и праздник для мальчика.

## Что проверено

- Mobile viewport `390×844` через headless Chrome и CDP.
- Длинные хабы и каталоги:
  - `/stati`;
  - `/podboroki`;
  - `/spektakli`;
  - `/uslugi`;
  - `/prazdniki`.
- Новые материалы:
  - `/stati/detskiy-prazdnik-v-torgovom-tsentre`;
  - `/stati/detskiy-prazdnik-v-parke`;
  - `/podboroki/prazdnik-dlya-devochki`;
  - `/podboroki/prazdnik-dlya-malchika`.

## Доказательства

- Для всех проверенных страниц CDP-проверка показала:
  - `clientWidth=390`;
  - `scrollWidth=390`;
  - `bodyScrollWidth=390`;
  - `hasHorizontal=false`.
- В проверенных хабах `.listing` остается внутри `left=16`, `right=374`, `width=358`.
- В новых материалах `.article-gallery` и `.article-next` остаются внутри `left=32`, `right=358`, `width=326`.
- Нижняя мобильная CTA-панель занимает `366px` ширины внутри viewport.
- `npm run build` прошел успешно.
- Количество статических страниц осталось `68`.

## Следствие

Новый сценарно-площадочный пакет не сломал мобильный интерфейс. Можно переходить к визуальному качеству ключевых посадочных или продолжать следующий контентный пакет с повторной мобильной проверкой после накопления.
