# 050-1 — Доработан существующий попап

2026-10-10. PartyAssistantDialog получил корпоративный режим и выбор общего числа гостей. Карточки трёх масштабов открывают это же окно с предвыбором; hero, расчёт, финальный CTA и мобильная кнопка открывают его без перехода со страницы. Подсказка и пример запроса отражают число гостей. На странице сохранена простая контактная форма, удалены состояние выбора карточки и сводка масштаба.

Доказательства: `npm run lint` и `npm run build` прошли; [браузерная проверка](../../reports/050-popup-browser.json) подтверждает один диалог, все три предвыбора и отсутствие селектора/сводки в обычной форме страницы.

Результат: запрос идёт через существующее окно, карточки передают масштаб, простая форма не содержит количества гостей. Завершён локально.
