# 004-10 — rich-блоки для ранних материалов

## Задача

Применить расширенную модель материалов к ранним страницам контент-машины, чтобы старые материалы не уступали новым по структуре SEO-портала.

## Что сделано

- Обогащены ранние материалы:
  - `/stati/kak-vybrat-spektakl-na-den-rozhdeniya`;
  - `/kejsy/piratskiy-den-rozhdeniya-7-let`;
  - `/podboroki/spektakli-dlya-5-7-let`;
  - `/stati/detskiy-prazdnik-doma-ili-v-restorane`;
  - `/kejsy/prazdnik-v-detskom-sadu`.
- В каждый материал добавлены:
  - авторская заметка;
  - галерея;
  - блок `Что выбрать дальше`;
  - рекламный слот в середине материала;
  - индивидуальная sidebar-метка рекламного места.
- Проверено, что все изображения из `content-data.ts` существуют в `public/images/legacy`.

## Доказательства

- Проверка путей изображений не вернула отсутствующих файлов.
- `npm run build` прошел успешно.
- Количество статических страниц осталось `63`, так как обновлялись существующие материалы.
- Локальный production-preview перезапущен на `http://localhost:4311`.
- HTML обновленных страниц содержит `article-gallery`, `ad-mid-content-page` и `article-next`.
- Проверены уникальные авторские заметки:
  - `Не начинайте с героя`;
  - `Почему пиратская тема держит внимание`;
  - `Возраст 5-7 любит ясные правила`;
  - `Площадка меняет сценарий сильнее, чем кажется`;
  - `В саду важна управляемость группы`.

## Следствие

Ранние материалы теперь соответствуют текущему стандарту SEO-портала: дают больше визуального доверия, внутренней перелинковки и мест под рекламу. Следующий разумный шаг — мобильная проверка длинных каталогов и накопленных хабов.
