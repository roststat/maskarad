# 004-61 — Индивидуальные и образовательные праздники

## Результат

Добавлены посадочные:

- `/prazdniki/individualnyy-detskiy-prazdnik`;
- `/prazdniki/obrazovatelnyy-detskiy-prazdnik`.

Страница индивидуального праздника объединяет два близких архивных интента: индивидуальный и эксклюзивный праздник. Отдельная страница образовательного праздника описывает сценарий с игровой подачей знаний и обязательным согласованием с учреждением.

Три старых URL получили постоянные точные редиректы. После этого среди широких назначений остаются преимущественно общие хабы, исторические и служебные URL, партнерские страницы и каталоги — создавать для них дубликаты не требуется.

## Доказательства

- `npm run seo:predeploy` прошел: покрытие 163 внутренних старых URL, аудит 179 правил, alt, TypeScript и production-сборка 127 статических страниц.
- `npm run seo:migration-relevance` показал 28 широких тематических назначений вместо 31; URL, покрытых только catch-all-правилом, нет.
