# 004-12 — пакет материалов про ТЦ, парк, класс и сценарии по ребенку

## Задача

Продолжить рост SEO-портала материалами под площадочные и сценарные запросы: торговый центр, парк, школьный класс, праздник для девочки и праздник для мальчика.

## Что сделано

- Добавлена статья `/stati/detskiy-prazdnik-v-torgovom-tsentre`.
- Добавлена статья `/stati/detskiy-prazdnik-v-parke`.
- Добавлена статья `/stati/prazdnik-dlya-klassa`.
- Добавлена подборка `/podboroki/prazdnik-dlya-devochki`.
- Добавлена подборка `/podboroki/prazdnik-dlya-malchika`.
- Хабы `/stati` и `/podboroki` получили ссылки на новые материалы.
- Все новые материалы сделаны в расширенной модели:
  - `Article` и `BreadcrumbList`;
  - авторская заметка;
  - галерея;
  - блок `Что выбрать дальше`;
  - рекламный слот в середине страницы;
  - отдельная sidebar-метка рекламного места.
- Проверено, что все изображения из `content-data.ts` существуют в `public/images/legacy`.

## Доказательства

- `npm run build` прошел успешно.
- Количество статических страниц выросло с `63` до `68`.
- Локальный production-preview перезапущен на `http://localhost:4311`.
- Все новые URL вернули `200 OK`:
  - `/stati/detskiy-prazdnik-v-torgovom-tsentre`;
  - `/stati/detskiy-prazdnik-v-parke`;
  - `/stati/prazdnik-dlya-klassa`;
  - `/podboroki/prazdnik-dlya-devochki`;
  - `/podboroki/prazdnik-dlya-malchika`.
- `sitemap.xml` содержит все пять новых URL.
- HTML новых страниц содержит `Article`, `BreadcrumbList`, `article-gallery`, `ad-mid-content-page` и `article-next`.
- Проверены уникальные авторские заметки:
  - `ТЦ любит предсказуемый тайминг`;
  - `Парк требует границ`;
  - `Класс нельзя вести как обычный день рождения`;
  - `Не сводить выбор к розовой теме`;
  - `Активность должна иметь правила`.

## Следствие

Портал закрыл еще один слой спроса: площадки с особыми условиями и родительские запросы по сценарию для ребенка. После этого пакета стоит снова проверить мобильный viewport длинных хабов или перейти к точной визуальной работе с фото ключевых посадочных.
