# 004-46 — Сценарий праздника Букваря

## Результат

Для активной старой страницы `/scenarii/detskii-prazdnik-bukvarya.html` создан материал `/stati/prazdnik-bukvarya-scenariy-dlya-1-klassa`. В нем есть план события для первого класса, роли детей, задания, финал и вопросы подготовки. Страница добавлена в `/stati` и связана с хабом сценариев. Архивное фото подписано как иллюстрация, без утверждения, что оно снято на празднике Букваря.

Старый URL ведет на материал постоянным редиректом Next.js со статусом `308`.

## Доказательства

- `npm run seo:predeploy` прошел: покрытие 163 внутренних старых URL, аудит 179 правил, alt, TypeScript и сборка 92 статических страниц.
- Локальный production-сервер: старый URL ответил `308` с точным `Location`, новая страница — `200 OK`; `npm run seo:prelaunch -- http://localhost:4310` прошел `12/12`.
- `npm run seo:migration-relevance`: широких назначений стало `80` вместо `81`.

Проверка индексации и поисковых позиций возможна только после запуска на выбранном сервере.
