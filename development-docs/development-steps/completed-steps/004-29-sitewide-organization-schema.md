# Подшаг 004-29 — site-wide Organization schema

## Результат

В корневой layout добавлена единая JSON-LD-сущность `Organization` для театра «Маскарад». Она содержит только подтверждённые данные: название, сайт, телефон, зону работы и контактный тип.

## Доказательство

`npm run build` проходит; JSON-LD отдается на всех страницах через корневой layout.

## Ограничение

Адрес, рейтинг, соцсети, часы работы и другие свойства не добавлялись до подтверждения владельцем.
