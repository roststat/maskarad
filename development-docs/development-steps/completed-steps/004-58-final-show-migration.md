# 004-58 — Завершение миграции самостоятельных спектаклей

## Результат

Добавлены отдельные посадочные:

- `/spektakli/skazka-elfov`;
- `/spektakli/shkola-volshebnic`.

Старые URL «Сказка эльфов» и «Школа волшебниц Винкс» получили постоянные точные редиректы на эти страницы. Обе темы описаны как самостоятельные безопасные игровые форматы, а архивные кадры подписаны как иллюстрации.

После этого в аудите остались три широких URL из группы спектаклей — это главная интерактивного раздела и два общих каталога (`/detskii-prazdnik/`, `/teatr/spektakl/`, `/teatr/spektakl/index.html`). Их назначение на каталог `/spektakli` релевантно; создавать три дубликата не нужно.

## Доказательства

- `npm run seo:predeploy` прошел: покрытие 163 внутренних старых URL, аудит 179 правил, alt, TypeScript и production-сборка 121 статической страницы.
- `npm run seo:migration-relevance` показал 38 широких тематических назначений вместо 40; URL, покрытых только catch-all-правилом, нет.
