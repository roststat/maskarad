# 004-11 — мобильная проверка накопленного SEO-портала

## Задача

Проверить длинные каталоги и контентные хабы после накопления материалов, чтобы рост SEO-портала не сломал мобильный UX.

## Что проверено

- Mobile viewport `390×844` через headless Chrome и CDP.
- Основные длинные каталоги:
  - `/spektakli`;
  - `/uslugi`;
  - `/prazdniki`.
- Контентные хабы:
  - `/stati`;
  - `/podboroki`;
  - `/kejsy`.
- Длинные материалы:
  - `/stati/kak-vybrat-spektakl-na-den-rozhdeniya`;
  - `/podboroki/nedorogoy-detskiy-prazdnik`.
- Раскрытое мобильное меню на:
  - `/spektakli`;
  - `/stati`;
  - `/podboroki`.

## Доказательства

- Для всех проверенных страниц CDP-проверка показала `clientWidth=390`, `scrollWidth=390`, `hasHorizontal=false`.
- Для раскрытого меню:
  - `navBox.width=358`;
  - `navBox.left=16`;
  - `navBox.right=374`;
  - `menuExpanded=true`;
  - горизонтального переполнения нет.
- Нижняя мобильная CTA-панель на проверенных страницах занимает `366px` ширины внутри viewport.
- `npm run build` прошел успешно.
- Количество статических страниц осталось `63`.

## Следствие

Накопление материалов и длинные списки не создали горизонтальный скролл на мобильном. Можно продолжать наращивать портал, но после следующего крупного пакета страниц стоит снова делать такую проверку.
