# 008.1 — Два окна помощника

Быстрый запрос теперь содержит свободный текст, голосовой ввод, имя, телефон, согласие и отправку организатору. Отдельная кнопка «Собрать полноценный бриф с ИИ» имеет подпись «Для профессионалов». Во втором окне размещены рекомендации, диалог, голосовой ввод, черновик брифа и PDF. Кнопка отправки брифа обращается к организатору.

Доказательства: `npm run lint` и `npm run build` прошли; в локальном браузере видны оба окна, первый экран без PDF и ИИ, второй — с рекомендациями и начальным вопросом.

Исторический итог: решение владельца от 2026-10-06 отменило ИИ-бриф; текущая реализация описана в `008-3-remove-ai-brief.md`.
