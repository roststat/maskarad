# 020-1 — Текущий сайт проверен

9 октября 2026, Москва.

Результат одной строкой: **122/122 URL sitemap отвечают 200 с одним H1 и собственным canonical; внешний SEO smoke-test прошёл 12/12, при этом отдельная новогодняя ссылка возвращает 404 и 13 URL не имеют входящих ссылок из проверенного набора.**

Проверка свежести: репозиторий синхронизирован с origin/main. APP_HEALTH_URL не задан; серверный Git/BUILD_ID не проверен. Состояние сайта проверено публичными запросами. Существующие локальные изменения по видео сохранены.

Доказательства:

1. `npm run seo:prelaunch -- https://maskarad-teatr.ru`: 12/12.
2. [Реестр полного обхода](../../reports/020-seo-url-audit-2026-10-09.csv) и [сводка](../../reports/020-seo-audit-summary-2026-10-09.json): HTML-метаданные, H1, canonical, статус, ссылки, глубина пути, изображения и типы JSON-LD. Повторяющиеся title/description/H1 искались по точному значению; семантическое дублирование этим не исключено.
3. [Дополнительные запросы](../../reports/020-seo-extra-checks-2026-10-09.json): новогодний URL — 404; документы — 200/noindex; произвольный отсутствующий URL — 404/noindex.
4. Браузер: главная и «Золушка» при 390 px имеют scrollWidth 390, меню открывается; основной кадр программы загрузился, плеер в main отсутствует. Остальные lazy-loading изображения не объявлялись сломанными. Размер окна возвращён к исходному.

Метод: публичный sitemap, HTTP-запросы максимум в три потока, разбор серверного HTML; граф ссылок построен по 122 страницам, входящие ссылки не включают ссылку страницы на себя. Проиндексированность и внешние ссылки не измерены. Админка, секреты и боевые заявки не читались; формы не отправлялись.

Исходные модели сопоставлены с публичным набором: 64 посадочные, 8 общих страниц, 3 хаба, 45 контентных материалов; каталог — 35 спектаклей и 10 основных услуг. Анализ цен, отзывов, кейсов и навигации включён в [стратегию](../../reports/020-seo-growth-strategy-2026-10-09.md).
