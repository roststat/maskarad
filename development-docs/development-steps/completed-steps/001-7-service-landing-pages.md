# 001-7 — Посадочные страниц услуг

Дата завершения: 2026-10-03.

## Что сделано

Добавлены отдельные SEO-посадочные для услуг из старого сайта:

- `/uslugi/cirkovye-fokusy`;
- `/uslugi/kukolnyy-spektakl`;
- `/uslugi/oformlenie-sharami`.

Старые страницы использованы как источник URL, заголовков и поискового интента. Новые тексты написаны заново под текущий UX-шаблон: первый экран, факты, смысловые блоки, что входит, FAQ, связанные страницы и заявка.

## Редиректы

Добавлены точные постоянные редиректы:

- `/detskie-uslugi/fokusy.html` → `/uslugi/cirkovye-fokusy`;
- `/detskie-uslugi/kukolnyy-spektakl.html` → `/uslugi/kukolnyy-spektakl`;
- `/detskie-uslugi/oformlenie-sharami.html` → `/uslugi/oformlenie-sharami`.

## Медиа

Из FTP-архива старого сайта в `public/images/legacy/` добавлены:

- `cirkovye-fokusy.jpg`;
- `oformlenie-sharami.jpg`.

Для `kukolnyy-spektakl.jpg` временно использован общий архивный театральный кадр, потому что специфичное фото кукольного спектакля в быстром отборе не найдено.

## Доказательства

- `npm run build` прошел успешно; количество статических страниц выросло до 36.
- Локальный сервер `4311` вернул `200 OK` для всех трех новых страниц.
- Старые URL вернули постоянные редиректы на новые страницы.
- `sitemap.xml` содержит все три новых URL.

## Что осталось

- Разобрать следующие `service`-URL из старого сайта: фото, видео, кейтеринг, спецэффекты, аттракционы.
- Отобрать более точное фото для кукольного спектакля или запросить его у владельца.
- Проверить мобильный вид каталога `/uslugi` после расширения.
