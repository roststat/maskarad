# 048-2 — Меню открывает начало страницы

2026-10-10.

## Причина и исправление

Исходная версия воспроизвела возврат `/uslugi` → меню `/spektakli` → меню `/uslugi` на scrollY=580; hero оказался обрезан. Локальное руководство Next.js Link описывает сохранение позиции либо прокрутку к первому элементу Page, что не гарантирует начало документа.

PageStartLink используется в пунктах меню и ссылке логотипа. При клиентском переходе стандартное управление прокруткой отключено; после появления выбранного маршрута useLayoutEffect сбрасывает scrollY в 0 без плавной анимации. При выборе текущей страницы сброс происходит сразу. Меню закрывается и при выборе текущего маршрута. Модификаторы открытия новой вкладки не вызывают onNavigate. Обработчик не подписывается на всю историю и не вмешивается в якоря заявок или фото-попап.
