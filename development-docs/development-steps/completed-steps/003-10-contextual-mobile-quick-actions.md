# 003-10 — контекстная мобильная панель быстрых действий

## Задача

После появления рабочих посадочных и формы заявки нижняя мобильная панель оставалась универсальной. На длинных каталогах и SEO-страницах лучше показывать действие, соответствующее текущему разделу: спектакли, услуги, праздники, цены или контакты.

## Что сделано

- Добавлен клиентский компонент `MobileQuickActions`.
- Панель определяет текущий путь и меняет текст основной кнопки:
  - `/spektakli/*` → `Подобрать спектакль`;
  - `/uslugi/*` → `Собрать программу`;
  - `/prazdniki/*` → `Обсудить праздник`;
  - `/tseny` → `Уточнить цену`;
  - `/kontakty` → `Написать`.
- Панель оставляет вторым быстрым действием звонок.
- CSS панели доработан под длинные подписи на узком экране: гибкие колонки, явные `min-width: 0`, компактный размер текста и стабильная высота.

## Доказательства

- `npm run build` прошел успешно.
- Локальная production-проверка `/spektakli` вернула `200 OK`.
- Локальная production-проверка `/spektakli/piraty-karibskogo-morya` вернула `200 OK`.
- HTML `/spektakli` содержит `mobile-quick-actions` и `Подобрать спектакль`.
- HTML `/uslugi` содержит `mobile-quick-actions`, `Собрать программу`, `10 страниц уже раскрыты подробно`, `без черновых карточек`.
- AX-проверка `/spektakli` видит карточки каталога, форму заявки и поля формы.

## Следствие

Мобильная конверсия стала контекстнее: пользователь видит не абстрактную заявку, а действие, совпадающее с текущим разделом. Это сохраняет простой путь на длинных SEO-страницах.
