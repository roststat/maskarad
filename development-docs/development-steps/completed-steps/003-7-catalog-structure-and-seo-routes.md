# 003-7 — Структура каталогов и SEO-маршруты

Дата завершения: 2026-10-03.

## Что сделано

- Каталоги `/spektakli`, `/uslugi`, `/prazdniki`, `/tseny`, `/foto-video`, `/kontakty`, `/otzyvy-pressa`, `/o-teatre` переведены с простого списка строк на структурированные карточки.
- Для уже созданных SEO-посадочных добавлены прямые ссылки из каталогов:
  - спектакли: `Золушка`, `Алиса`, `Пеппи`, `Пираты`;
  - услуги: `Аквагрим`, `Шоу мыльных пузырей`, `Мастер-классы`;
  - праздники: `День рождения`, `Детский сад`, `Школа`, `Выпускной`, `Корпоративный новогодний праздник`.
- Для еще не перенесенных направлений добавлена честная пометка `в очереди миграции`, чтобы каталог показывал объем старого сайта, но не обещал готовую посадочную.
- На типовые страницы добавлен блок `Дальше по структуре`: связанные маршруты ведут пользователя к праздникам, услугам, спектаклям, цене или заявке.
- Карточки каталогов получили отдельные стили `listing-card`; связанные маршруты получили адаптивный блок `catalog-related`.

## Почему это важно

Каталог теперь работает как SEO-развилка, а не как декоративный список. Это помогает сохранить ощущение большого театра с объемом программ и одновременно направляет пользователя к уже подготовленным посадочным страницам.

## Доказательства

- `npm run build` прошел успешно.
- Локальная HTTP-проверка на временном сервере `4311` вернула `200 OK` для `/spektakli`, `/uslugi`, `/prazdniki`, `/spektakli/zolushka`, `/uslugi/master-klassy`.
- В браузере проверена структура `/spektakli`: первые сильные спектакли стали ссылками на посадочные, остальные направления отображаются как очередь миграции.
