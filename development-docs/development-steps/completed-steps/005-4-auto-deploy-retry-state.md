# 005-4 — Повтор неудачного автодеплоя

## Результат

`scripts/server/auto-deploy.sh` запоминает последний успешно запущенный коммит в Git metadata. Ранний выход допустим только если текущий `HEAD`, `origin/main` и этот маркер совпадают. Маркер записывается после успешного `npm ci`, `seo:predeploy` и `pm2 reload`.

При сбое сборки или перезагрузки следующий запуск таймера повторит попытку даже тогда, когда серверный `HEAD` уже был обновлен. Перед TypeScript-проверкой удаляются только `.next/types`: эти сгенерированные файлы могут ссылаться на страницы, удаленные в новом коммите. Отсутствие `.next/BUILD_ID` также заставляет повторить сборку.

## Доказательство

Локально прошли `bash scripts/server/test-auto-deploy.sh` (отказ `pm2 reload`, повтор, удаление старых типов, повтор при исчезновении сборки и пропуск после успеха), `bash -n` для обоих скриптов, `git diff --check` и `npm run seo:predeploy` (129 статических страниц). Серверный запуск нового сценария проверяется после публикации коммита.
