# 056-2 — редактор с контекстом и восстановлением соединения

10 октября 2026. Подшаг завершён локально; публикация — 056-3.

## Изменения

- Запрос включает только текст и проверенный сервером корпоративный контекст из фиксированных вариантов гостей. Имя и телефон не передаются.
- Модель получает масштаб как общее число гостей, включая взрослых. Вступление с количеством формирует сервер, чтобы число не потерялось и не превратилось в число детей.
- Короткие пожелания оформляются компактно (тело до 350 символов); «полный расклад» — просьба о вариантах программы, составе, условиях проведения и бюджете. Новые услуги и пожелания запрещены. Первый пробный результат был слишком подробным; он отклонён при проверке, инструкция усилена примером и ограничением длины.
- Изменение выбора обновляет созданное вступление, в том числе после ручной правки тела. Повторная ИИ правка не отправляет ранее созданное вступление повторно; пользовательские правки/диктовка и возврат исходника сохраняются.
- До двух попыток, общий серверный предел 50 с, клиентский 55 с. Сетевой отказ включает альтернативный DNS того же hostname; перебираются полученные IPv4-адреса. TLS-проверка и исходный адрес сервиса сохранены, IP не фиксируется. Успешный резервный путь предпочитается 5 минут.
- DNS через 1.1.1.1 используется только в редакторе, системные настройки не меняются. В DNS-запросе только hostname; ключ и текст туда не отправляются. Журнал содержит класс/допустимый код ошибки, HTTP-статус и номер попытки, без пожеланий, имени, телефона, ключей и полных ответов сервиса.

## Доказательства

- Новый код API проверен в памяти production-сервера: HTTP 200, 1,566 с; пример владельца → корректное вступление «до 250–300 гостей, включая взрослых» и просьба подготовить подробное предложение. Сам резервный транспорт с реальным сервисом отдельно вернул HTTP 200 за 1,464 с.
- После уточнения инструкции отдельный реальный ответ на «40 детей 6–10 лет» с выбором «более 500 гостей» — HTTP 200 за 2,328 с: общее число и детские сведения сохранены отдельно, вопросов о выдуманном прежнем масштабе нет.
- `node scripts/server/check-text-editor.cjs`: 10/10 — пустой ввод, неправильный контекст, отсутствие контактных полей, общий режим, неизвестное число, восстановление после connection timeout, ограниченный retry, неполный/слишком длинный ответ и безопасный журнал.
- Полный локальный seo:predeploy прошёл; итоговая дополнительная сборка после правок полей — 198 страниц, TypeScript; FAQ 122/122 и редиректы 179 ранее прошли в том же пакете.
- Браузер: пример владельца оформлен, medium → small заменил число без повтора, повторная правка и точный возврат черновика проверены. На окончательной версии пустое поле получает подсказку; после ручного добавления «Детей будет 40, возраст 6–10 лет» изменение medium → large сохраняет эти сведения и заменяет только созданное вступление.

Настоящие заявки и голосовой сервис в проверке не использовались. Внешний ИИ-сервис может быть недоступен: после исчерпания двух попыток черновик сохраняется и показывается прежнее понятное сообщение. Секреты и хранилище не менялись.
