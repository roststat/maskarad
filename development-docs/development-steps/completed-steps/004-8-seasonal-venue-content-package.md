# 004-8 — пакет материалов про выпускной, Новый год, дом и ресторан

## Задача

Продолжить рост SEO-портала страницами под сезонные, площадочные и коммерческие запросы: выпускной, новогодние программы, аниматоры на дом и детский праздник в ресторане.

## Что сделано

- Добавлена подборка `/podboroki/idei-dlya-vypusknogo`.
- Добавлена подборка `/podboroki/novogodnie-programmy-dlya-detey`.
- Добавлена статья `/stati/animatory-na-dom-kak-vybrat-programmu`.
- Добавлена статья `/stati/detskiy-prazdnik-v-restorane`.
- Хабы `/stati` и `/podboroki` получили ссылки на новые материалы.
- Все новые материалы сделаны в расширенной модели:
  - `Article` и `BreadcrumbList`;
  - авторская заметка;
  - галерея;
  - блок `Что выбрать дальше`;
  - рекламный слот в середине страницы;
  - отдельная sidebar-метка рекламного места.
- Исправлен путь к изображению в подборке 8-10 лет: вместо отсутствующего `akvagrim01.jpg` используется существующая `fotosyomka.jpg`.

## Доказательства

- `npm run build` прошел успешно.
- Количество статических страниц выросло с `55` до `59`.
- Локальный production-preview перезапущен на `http://localhost:4311`.
- Все новые URL вернули `200 OK`:
  - `/podboroki/idei-dlya-vypusknogo`;
  - `/podboroki/novogodnie-programmy-dlya-detey`;
  - `/stati/animatory-na-dom-kak-vybrat-programmu`;
  - `/stati/detskiy-prazdnik-v-restorane`.
- `sitemap.xml` содержит все четыре новых URL.
- HTML новых страниц содержит `Article`, `BreadcrumbList`, `article-gallery`, `ad-mid-content-page` и `article-next`.
- Проверены уникальные редакторские блоки:

  - `Детская зона важнее декора`.

## Следствие

SEO-портал расширился на сезонные и площадочные кластеры. Следующий логичный шаг — добрать возраст 11-13, усилить старые материалы новыми rich-блоками и затем проверить мобильный viewport на длинных каталогах после накопления контента.
