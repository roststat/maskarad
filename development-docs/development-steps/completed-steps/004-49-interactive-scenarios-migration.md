# 004-49 — Хаб игрового сценария для группы

## Результат

Создана статья `/stati/igrovoy-scenariy-dlya-detskogo-prazdnika`. Она объединяет старые сценарии «Город мастеров», «Играем с Несмеяной», «Чудесная карусель», «Путешествие на поляну игр» и «Карнавал сказочных героев» в современный материал о программе с героями, маршрутными заданиями и общим финалом.

Пять старых URL получили точные постоянные редиректы. Такой перенос сохраняет общий поисковой интент, не создавая пять страниц с почти одинаковым содержанием и неподтвержденными программами.

## Доказательства

- `npm run seo:predeploy` прошел: покрытие 163 внутренних старых URL, аудит 179 правил, alt, TypeScript и production-сборка 98 статических страниц.
- `npm run seo:migration-relevance` показал 68 широких тематических назначений вместо 73; URL, покрытых только catch-all-правилом, нет.
