# 004-57 — Посадочные персонажных программ

## Результат

Добавлены отдельные посадочные:

- `/spektakli/skazka-shreka`;
- `/spektakli/smurfiki`;
- `/spektakli/supergeroi`.

Страницы описывают самостоятельные интерактивные сценарии, а не копируют сюжеты произведений. Архивные изображения помечены как иллюстрации. Для каждого старого URL добавлен постоянный точный редирект на новую релевантную страницу.

После этого из самостоятельных архивных тем спектаклей без точного назначения остаются только «Сказка эльфов» и «Школа волшебниц Винкс»; прочие оставшиеся назначения — каталожные или служебные URL.

## Доказательства

- `npm run seo:predeploy` прошел: покрытие 163 внутренних старых URL, аудит 179 правил, alt, TypeScript и production-сборка 119 статических страниц.
- `npm run seo:migration-relevance` показал 40 широких тематических назначений вместо 43; URL, покрытых только catch-all-правилом, нет.
