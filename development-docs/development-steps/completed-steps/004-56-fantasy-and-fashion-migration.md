# 004-56 — Фантастические форматы и Fashion-выпускной

## Результат

Добавлены отдельные посадочные:

- `/spektakli/avatar`;
- `/prazdniki/vypusknoy-v-stile-fashion`;
- `/spektakli/pyatyy-element`.

Fashion-праздник перенесен в раздел выпускных, а не в каталог спектаклей, поскольку исходный интент — творческий выпускной. Темы «Аватар» и «Пятый элемент» описаны как самостоятельные возрастные игровые сценарии, а не как воспроизведение сюжетов произведений. Архивные изображения подписаны как иллюстрации.

Три старых URL получили постоянные точные редиректы на новые релевантные страницы.

## Доказательства

- `npm run seo:predeploy` прошел: покрытие 163 внутренних старых URL, аудит 179 правил, alt, TypeScript и production-сборка 116 статических страниц.
- `npm run seo:migration-relevance` показал 43 широких тематических назначения вместо 46; URL, покрытых только catch-all-правилом, нет.
