# 003-18 — Убрать рекламные места из публичного сайта

## Задача

По решению владельца убрать все публичные заглушки рекламных мест до отдельного решения о рекламе.

## Сделано

- Удалён общий компонент рекламного слота и его стили.
- Удалены вызовы слотов из шаблона статей, подборок, хабов и обычных посадочных.
- Удалён слот с отдельной корпоративной новогодней страницы.
- Поля `adSlots` в контентных данных не выводятся на сайт и временно сохранены как обратимые технические метаданные.

## Доказательство

- `npm run lint` — успешно (`tsc --noEmit`).
- `npm run build` — успешно; Next.js 16.3.5 собрал 129 маршрутов.
- `git diff --check` — успешно.
- Поиск `AdSlot`, `ad-slot`, `data-ad-slot` в публичном коде приложения не нашёл результатов.

Публикация и отправка в GitHub не выполняются.
