# Подшаг 004-26 — автоматическая проверка старых URL

## Результат

Добавлена команда `npm run seo:old-url-coverage`. Она читает инвентаризацию старого сайта из `development-docs/reports/old-site-inventory/urls.csv`, извлекает redirect-правила из `next.config.ts` и проверяет, что каждый внутренний старый URL попадает хотя бы под одно правило.

## Зачем

SEO-миграция не должна зависеть от ручной сверки после каждого нового маршрута. Проверка ловит забытые адреса до деплоя и сохраняет правило: старый внутренний URL должен получить отдельную посадочную или постоянный редирект.

## Доказательство

Команда проходит для текущей карты старого сайта: все 163 инвентаризированных внутренних URL покрыты явными правилами редиректов. Catch-all-only остаток равен нулю: все старые адреса теперь видны в проверяемой карте, включая исторические спектакли, сценарии, услуги, сезонные страницы и служебные URL.
