# 004-3 — второй пакет материалов SEO-портала

## Задача

Начать наращивать страничную массу не “блогом ради блога”, а редакционными SEO-материалами под разные поисковые намерения: возраст ребенка, площадка праздника, корпоративный формат и реальные кейсы.

## Что сделано

- В `app/content-data.ts` добавлены новые материалы:
  - `/podboroki/prazdniki-dlya-detey-3-4-goda`;
  - `/stati/detskiy-prazdnik-doma-ili-v-restorane`;
  - `/kejsy/prazdnik-v-detskom-sadu`;
  - `/stati/korporativnaya-elka-dlya-detey-sotrudnikov`.
- Хабы `/stati`, `/kejsy`, `/podboroki` получили ссылки на новые материалы.
- Новые страницы используют существующий SEO-шаблон:
  - хлебные крошки;
  - `Article` schema;
  - `BreadcrumbList`;
  - даты публикации и обновления;
  - факты;
  - основной текст;
  - FAQ;
  - связанные страницы;
  - рекламные слоты.
- Sitemap автоматически расширился на новые материалы.

## Доказательства

- `npm run build` прошел успешно.
- Количество статических страниц выросло до `53`.
- `curl -I` вернул `200 OK` для:
  - `/podboroki/prazdniki-dlya-detey-3-4-goda`;
  - `/stati/detskiy-prazdnik-doma-ili-v-restorane`;
  - `/kejsy/prazdnik-v-detskom-sadu`;
  - `/stati/korporativnaya-elka-dlya-detey-sotrudnikov`.
- Локальный `sitemap.xml` содержит все четыре новых URL.
- HTML статьи `/stati/korporativnaya-elka-dlya-detey-sotrudnikov` содержит `Article`, `BreadcrumbList`, `Хлебные крошки`, `data-ad-slot`, дату публикации.
- HTML `/stati` содержит карточки новых материалов про возраст 3-4, дом/ресторан и корпоративную елку.

## Следствие

SEO-портал получил второй слой редакционных страниц. Теперь можно повторять выпуск материалов быстрее: следующий подшаг — визуально проверить мобильный вид хабов и материалов, затем расширить модель под галереи, авторские заметки, блоки выбора и более точные рекламные места.
