# 004-55 — Зимние спектакли и пиратское приключение

## Результат

Добавлены отдельные зимние посадочные:

- `/spektakli/novogodnyy-ekspress`;
- `/spektakli/novyy-god-na-snezhnoy-planete`.

Архивная пиратская страница `/detskii-prazdnik/piraty.html` не получила дубликат: она направлена на уже существующую релевантную посадочную `/spektakli/piraty-karibskogo-morya`.

Два зимних URL получили отдельные постоянные точные редиректы. Во всех новых страницах архивный кадр честно обозначен как иллюстрация формата, а не как текущая съемка постановки.

## Доказательства

- `npm run seo:predeploy` прошел: покрытие 163 внутренних старых URL, аудит 179 правил, alt, TypeScript и production-сборка 113 статических страниц.
- `npm run seo:migration-relevance` показал 46 широких тематических назначений вместо 49; URL, покрытых только catch-all-правилом, нет.
