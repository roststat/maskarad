# 074-2 — SEO персональной страницы

15 октября 2026. Именной title/description, canonical, Open Graph profile и портрет, Twitter card, индексируемая статическая страница. JSON-LD: ProfilePage, Person с полным ФИО и связью с организацией, BreadcrumbList, FAQPage с пятью видимыми ответами. Общая Organization ссылается на основателя по стабильному Person ID.

Страница включена в sitemap; входы — меню всех трёх аудиторий, подвал и карточка/связанный переход на «О театре». Дата «О театре» обновляется по фактическому содержательному изменению, прочие старые даты не переписываются.

Доказательства: полный `npm run seo:predeploy` прошёл (124 URL, типы, сборка, редиректы, alt, юридический gate и точное совпадение пяти FAQ). Дополнительно собранный HTML проверяется на canonical, один H1, пять iframe и связанный Person/ProfilePage.

Это техническая подготовка к индексации; индексация, позиции и показы ещё не подтверждены.
