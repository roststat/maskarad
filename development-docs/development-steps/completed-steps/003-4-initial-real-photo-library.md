# 003-4 — Первый набор реальных фото из FTP-архива

Дата: 2026-10-02.

## Что сделано

- Из FTP-архива выбран первый набор реальных изображений театра.
- Файлы скопированы в `public/images/legacy/`, чтобы после переезда домена сайт не зависел от старого хостинга.
- Главный экран и базовая галерея переключены с удаленных URL `maskarad-teatr.ru` на локальные изображения.

## Файлы

- `public/images/legacy/interaktiv01.jpg` — сценический интерактив, используется на главной и в галерее.
- `public/images/legacy/piraty01.jpg` — пиратский спектакль, используется в галерее.
- `public/images/legacy/teatr-zolushka.jpg` — спектакль «Золушка», используется в галерее.
- `public/images/legacy/gallery4b.jpg` — отложен для следующих визуальных блоков.
- `public/images/legacy/gallery5b.jpg` — отложен для следующих визуальных блоков.

## Доказательства

- `rg "https://maskarad-teatr.ru|/images/legacy" app next.config.ts` больше не показывает удаленных URL изображений в UI.
- Размеры выбранных изображений проверены через `sips`.
- `npm run build` прошел успешно после подключения локальных изображений.
