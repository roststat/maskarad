# 003-15 — закреплённая шапка и каталог навигации

## Задача

Подготовить навигацию для растущего SEO-сайта: не делать ссылки «Для детей / взрослых / бизнеса» главным визуальным акцентом и дать пользователю читаемый путь к разделам и будущим уровням каталога.

## Что сделано

- Шапка закреплена фиксированно сверху, а контент получил безопасный отступ, поэтому меню остаётся доступным при прокрутке.
- Рабочая ширина шапки совпадает с шириной текстовых блоков сайта (`1160px`); `Меню` стоит слева, логотип строго по центру, телефон — справа. Кнопка заявки из шапки убрана.
- В шапке оставлена только кнопка `Меню` с иконкой из четырёх точек. Ссылки `Для детей`, `Для взрослых`, `Для бизнеса` перенесены внутрь каталога и стоят первой, слегка выделенной строкой `Подобрать по задаче`.
- Кнопка `Меню` открывает каталог из четырёх групп: `Праздники`, `Спектакли`, `Услуги`, `О театре`.
- В открытом состоянии кнопка меняет подпись на `Закрыть`, получает контрастный винный цвет и спокойную анимацию иконки — состояние каталога видно без догадки.
- Раскрытый каталог на desktop и планшете выровнен по полной рабочей ширине контентной сетки (`1160px`), а не ограничен случайной узкой панелью.
- На внутренних страницах хлебные крошки стали вторым уровнем закреплённой шапки. Они изначально компактнее основного меню, при прокрутке вниз сжимаются до тонкой полосы, при движении вверх или наведении на кнопку меню вновь раскрываются.
- Цепочка крошек выровнена по центру под логотипом.
- Крошки отделены от основной строки меню тонкой малоконтрастной полосой.
- Контраст разделителя немного усилен по замечанию владельца, чтобы граница оставалась лёгкой, но считывалась сразу.
- После проверки на светлом фоне разделитель увеличен до 2px и стал заметнее.
- Финальный вариант уточнён владельцем: снова тонкий 1px, но более тёмного винного оттенка.
- Кнопка меню увеличена и получила лёгкий золотисто-винный акцент, чтобы быть заметнее и дружелюбнее без конкуренции с логотипом.
- Стрелки у заголовков групп каталога убраны; сами группы получили тонкие ненавязчивые границы для более ясного разделения.
- Крошки показываются на всех контентных страницах, включая главную: на ней это единственный пункт `Главная`.
- Строка `Подобрать по задаче` стала переключателем контекста каталога: для детей, взрослых и бизнеса показываются разные группы и приоритетные переходы без перезагрузки страницы.
- Короткая оранжевая черта перед каждым надзаголовком заменена на утверждённую двухцветную маску, поэтому знак театра системно повторяется на всех страницах.
- Открытый каталог закрывается не только кнопкой и переходом по ссылке, но и нажатием на свободную область страницы.
- У каждой группы есть переход на хаб первого уровня и четыре приоритетные страницы второго уровня. Такая структура является основой для добавления третьего уровня внутри соответствующей группы, а не в постоянную шапку.
- В desktop-версии номер дополнен иконкой мобильного телефона с ненавязчивой анимацией звонка. На планшете остаётся только иконка, на мобильном экране — существующие быстрые кнопки звонка и заявки.
- На мобильном экране каталог открывается отдельной прокручиваемой панелью: две колонки до `440px` и одна колонка на более узких экранах, поэтому ссылки не сжимаются и не выходят за края.

## Доказательства

- `npm run lint` и `npm run build` прошли успешно после финальной адаптации; production-сборка содержит 128 статических страниц.
- Локальная браузерная проверка подтвердила раскрытие каталога со всеми 20 ссылками и закреплённую шапку после прокрутки страницы.
