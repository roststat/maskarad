# 008.2 — Диалог для подробного брифа

`/api/party-brief` принимает ограниченную историю реплик, передаёт её модели и возвращает следующий вопрос вместе с обновлённым брифом. Интерфейс хранит ответы, показывает вопросы, позволяет продолжать беседу и сохранить текущий бриф в PDF.

Доказательства: `npm run lint` и `npm run build` прошли, маршрут вошёл в production-сборку; локальный браузер показывает историю и поле ответа. Реальный ответ модели и отправка заявки не проверялись: тестовые интеграции не предоставлены, боевые данные и секреты не использовались.

Исторический итог: решение владельца от 2026-10-06 отменило ИИ-бриф; текущая реализация описана в `008-3-remove-ai-brief.md`.
