# 004-45 — Отдельный хаб сценариев праздников

## Результат

Старый раздел сценариев больше не теряется в общем `/stati`. Создана отдельная страница `/podboroki/scenarii-detskih-prazdnikov` с маршрутами по дню рождения, детскому саду, школе, выпускному, Новому году, возрасту и площадке.

Старые `/scenarii/` и `/scenarii/index.html` получили точные постоянные редиректы на новый хаб. Остальные старые сценарии пока не размножаются автоматически: для них нужна проверка актуальности и решение, какой материал действительно стоит публиковать.

## Доказательства

- `npm run seo:migration-relevance` — широких назначений стало `81` вместо `83`.
- `npm run seo:predeploy` — покрытие `163/163`, 179 редиректов без цепочек, image-alt, TypeScript и production-сборка прошли; собрано 91 статическая страница.
