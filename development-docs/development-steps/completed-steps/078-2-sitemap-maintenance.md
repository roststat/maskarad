# 078-2 — Автоматическое сопровождение

17 октября 2026. Правило сохранено в README и AGENTS.md. HTML-карта получает URL из `app/sitemap.ts`, названия из существующих данных. Новые записи каталогов и статей включаются при сборке/публикации. Новый отдельный маршрут требует URL и названия; отсутствие названия останавливает сборку.

`seo:html-sitemap` включён в штатный gate. Он сравнивает собранные индексируемые HTML, XML и видимое оглавление, проверяет дубли и наличие целей. Внутренние страницы ошибок Next.js исключены явно.

Доказательства: положительная проверка 125 URL + 4 документа; временная новая индексируемая HTML-страница без записи в карте вызвала ожидаемый отказ. Контрольная страница удалена.
