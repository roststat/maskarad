# 007.2 — Локальный бриф и PDF

Текст остаётся в браузере, пока посетитель не нажмёт «Собрать бриф с ИИ». Только это явное действие отправляет текст в `/api/party-brief`; сервер передаёт его OpenAI и возвращает отредактированный бриф. PDF создаётся на устройстве посетителя. Кнопка «Скачать PDF» появляется после первой успешной генерации, а кнопка ИИ остаётся доступной для повторной правки.

Доказательство: `npm run lint` и `npm run build` прошли. В браузере проверены отдельный бриф без контактных полей, зелёный микрофон, подсказка к диктовке и состояние до генерации. Публикация интерфейса подтверждена на Timeweb. Реальная генерация требует доступного региона OpenAI; проверка с Timeweb вернула `unsupported_country_region_territory`.
