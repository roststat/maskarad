# 007.2 — Локальный бриф и PDF

Нажатие «Составить черновик» формирует редактируемый шаблон прямо в браузере. PDF создаётся там же. Обычный путь не обращается к `/api/party-brief`; серверный OpenAI route по умолчанию закрыт флагом `BRIEF_AI_ENABLED`.

Доказательство: браузерный сценарий создал бриф без контактных полей и завершил действие «Скачать PDF для себя» сообщением об успехе; исходный код пути не содержит `fetch`. Прямой тест `/api/party-brief` вернул `503 assistant_disabled`. Содержимое скачанного файла через встроенный браузер не проверялось.
