# 004-43 — Точные посадочные для выпускного

## Результат

Содержательная проверка миграции показала 89 старых URL с широкими назначениями. В качестве первого приоритета выбраны три активных интента выпускного, которые раньше все вели на общий `/prazdniki/vypusknoy`.

Добавлены отдельные посадочные:

- `/prazdniki/vypusknoy-v-detskom-sadu`;
- `/prazdniki/vypusknoy-v-nachalnoy-shkole`;
- `/prazdniki/vypusknoy-v-11-klasse`.

Старые URL теперь получают точные постоянные редиректы на соответствующие страницы. Добавлен скрипт `npm run seo:migration-relevance`, который выявляет старые URL, ведущие на слишком общие каталоги.

## Доказательства

- `npm run seo:migration-relevance` — аудит обработал 356 URL и сохранил список оставшихся 89 широких назначений для приоритизации.
- `npm run seo:predeploy` — покрытие `163/163`, 179 редиректов без цепочек, image-alt, TypeScript и production-сборка прошли; собрано 87 статических страниц.
