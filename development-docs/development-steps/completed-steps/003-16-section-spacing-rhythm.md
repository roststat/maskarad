# 003-16 — вертикальный ритм между смысловыми блоками

## Задача

Сделать длинные страницы легче для чтения на едином светлом фоне: отделить самостоятельные этапы выбора и доверия воздухом, не превращая каждый раздел в цветную плашку.

## Что сделано

- В дизайн-систему добавлены два токена вертикального ритма: обычный для крупных смысловых переходов и компактный для логически близких блоков.
- Отступы применены к основным самостоятельным секциям главной, каталогов, SEO-посадочных, контентных хабов и статей: выбор, каталог, полезные материалы, FAQ, галерея и заявка.
- Для первого блока после героя и для блока после хлебных крошек используется более компактный интервал, чтобы начало страницы не стало пустым.
- Цветовая система и карточки не менялись: разделение достигнуто воздухом, а не добавлением новых фонов.
- Подвал вынесен в самостоятельную завершающую зону: перед ним действует компактный системный отступ, по всей ширине проходит более читаемый тонкий разделитель, а его фон лишь немного теплее основного.
- Технический публичный блок с путём исходной старой страницы удалён: он не несёт пользы посетителю и больше не создаёт лишний отступ перед заявкой.
- Удалены технические карточки-счётчики из каталогов; внутренние подписи фото о миграции и SEO не выводятся посетителям.

## Доказательства

- `npm run lint` и `npm run build` прошли успешно; production-сборка содержит 128 статических страниц.
- Локальная браузерная проверка главной подтвердила читаемое разделение между статистикой и блоком быстрого выбора при сохранённой закреплённой шапке.
