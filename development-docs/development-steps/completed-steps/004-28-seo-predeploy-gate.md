# Подшаг 004-28 — единый SEO pre-deploy gate

## Результат

Добавлена команда `npm run seo:predeploy`. Она последовательно проверяет покрытие старых URL, цепочки и циклы редиректов, затем запускает production-сборку.

## Доказательство

Команда должна завершаться успешно только при выполнении всех трёх условий: `163/163` старых URL покрыты, цепочек редиректов нет, Next.js собирает 84 страницы.

## Граница проверки

Команда не заменяет внешний smoke-test: после деплоя отдельно нужен `npm run seo:prelaunch -- <vercel-preview-url>` с публично доступным preview.
