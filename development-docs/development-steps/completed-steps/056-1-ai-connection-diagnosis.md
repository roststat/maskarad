# 056-1 — ошибка воспроизведена и классифицирована

10 октября 2026.

- Публичный `/api/text-edit`: пример владельца → HTTP 502 `editor_unavailable`, 10,5 с.
- Прямой запрос из сервера через прежнюю конфигурацию: Node fetch → `UND_ERR_CONNECT_TIMEOUT`, попытки соединения с двумя адресами:443, таймаут соединения 10 с. До ответа модели запрос не дошёл. Это сетевой сбой подключённого сервиса, не ошибка русского текста и не доказанный недостаток output tokens.
- Клиент отправлял только `{text}`: выбранное число гостей отсутствовало в запросе. Это отдельная причина потери контекста.

Доказательства: внешний HTTP + независимый запрос из серверного процесса. Настройки прочитаны в память, значения ключей не выводились; записи заявок не читались и не менялись. Доступность сети исследуется в 056-2.
