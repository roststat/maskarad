# 003-13 — открытая навигация по аудиториям и скрытое меню

## Задача

После сравнения с More Show нужно было упростить шапку: не показывать весь набор разделов сразу, а оставить видимыми только главные сценарии выбора аудитории.

## Что сделано

- Полное меню спрятано под кнопку `Меню`.
- В открытой части шапки оставлены три направления: `Для детей`, `Для взрослых`, `Для бизнеса`.
- Направления подключены к существующим безопасным маршрутам проекта, чтобы интерфейс уже работал без пустых страниц.
- Выпадающее меню закрывается при переходе по пункту.
- На мобильных экранах аудитории остаются горизонтально доступными, а полное меню раскрывается отдельной панелью.

## Доказательства

- `npm run build` прошел успешно.
- `/spektakli` вернул `200 OK` на локальном production-сервере.
- HTML `/spektakli` содержит `Для детей`, `Для взрослых`, `Для бизнеса`, `Меню`, `aria-expanded`, `Полное меню`, `Навигация по аудитории`.
- HTML `/` содержит те же элементы шапки.

## Следствие

Шапка стала ближе к интерфейсу крупного агентства: первый выбор строится вокруг аудитории клиента, а служебные разделы не перегружают верхний экран. Следующий UX-шаг — сделать отдельные сильные посадочные для `Для взрослых` и `Для бизнеса`, чтобы эти пункты вели не на временные существующие страницы, а на полноценные SEO-разделы.
