# 004-44 — Точные посадочные для архивных спектаклей

## Результат

Вынесены в отдельные новые SEO-посадочные три самостоятельных старых интента спектаклей:

- `/spektakli/vinni-puh`;
- `/spektakli/madagaskar`;
- `/spektakli/holodnoe-serdtse`.

Старые URL этих программ получили точные постоянные редиректы вместо общего `/spektakli`. Тексты написаны заново под современный сценарий выбора программы, без механического копирования старого сайта.

## Доказательства

- `npm run seo:migration-relevance` — широких назначений стало `83` вместо `89`.
- `npm run seo:predeploy` — покрытие `163/163`, 179 редиректов без цепочек, image-alt, TypeScript и production-сборка прошли; собрано 90 статических страниц.
