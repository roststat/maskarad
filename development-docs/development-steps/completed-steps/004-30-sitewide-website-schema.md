# Подшаг 004-30 — site-wide WebSite schema

## Результат

В корневой layout добавлена JSON-LD-сущность `WebSite`, связанная с `Organization` через publisher. Сайт теперь описывает отдельно ресурс и организацию, которая его публикует.

## Доказательство

`npm run build` проходит; схема отдается глобально через layout.

## Ограничение

`SearchAction` не добавлялся: публичного поиска по сайту пока нет.
