# 008.3 — Убран ИИ-бриф

По актуальному решению владельца оставлено одно окно короткого запроса организатору с текстом, диктовкой и отправкой. Второе окно, чат, генерация брифа, PDF, маршрут `/api/party-brief`, зависимости `pdfmake` и связанные стили удалены. История прежнего решения остаётся в Git и в описании шага.

Доказательства: `npm run lint`, `npm run build`, `git diff --check`; в локальном браузере после обновления виден только короткий запрос. Реальная доставка заявки не проверялась без тестового канала.
