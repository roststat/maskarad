# 080-3 — Публичная проверка

23 октября 2026. Матрица 28/28: HTTP/HTTPS × www/non-www × главная, контакты с UTM/кодированным query/пустым параметром, старая карта с query, robots, sitemap, зимняя страница и неизвестный адрес.

HTTPS www даёт 308 прямо на HTTPS non-www, HTTP — 301 прямо на HTTPS non-www. `/karta.html` на всех четырёх origins даёт один 308 прямо на `/karta-sayta`, query сохраняется. Конечные страницы — 200; неизвестный тестовый URL остаётся 404. Проверка сертификатов включена на обоих HTTPS-именах.
