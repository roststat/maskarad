# 003-14 — тест палитры театра и временный вариант логотипа

## Задача

Сохранить узнаваемую цветовую связь со старым сайтом до финального редизайна и подготовить отдельный экран для согласования палитры, не меняя работающие коммерческие страницы.

## Что сделано

- Добавлена изолированная тестовая страница `/test-palette` с театральной палитрой: глубокий синий, красный занавес, тёплый золотой акцент и светлый фон контента.
- Из старой шапки `top.jpg` выделен ориентир для знака: двухцветная красно-белая театральная маска и надпись «Маскарад».
- Добавлен временный растровый вариант знака `public/images/legacy/maskarad-logo-test.png` только для тестового экрана; основной логотип сайта не заменялся.
- Подготовлен отдельный файл `public/images/legacy/maskarad-mask-transparent.png`: только двухцветная театральная маска, без текста и с прозрачным фоном.
- Тестовый маршрут закрыт от индексации через `robots: noindex, nofollow`, поэтому не влияет на поисковую миграцию.

## Доказательства

- Локально `npm run lint && npm run build` прошли успешно; сборка содержит статический маршрут `/test-palette`.
- На production-сервере 2026-10-05 `/test-palette`, исходный PNG и оптимизированное изображение вернули `200 OK`.
- По `https://maskarad-teatr.ru/test-palette` и `https://maskarad-teatr.ru/images/legacy/maskarad-logo-test.png` получены `200 OK`.
- Отдельная маска имеет разрешение `1282×1227`, формат PNG RGBA и подтверждённый alpha-канал.

## Решение владельца после теста

Владелец отклонил тестовую страницу палитры: она удаляется вместе с её стилями и тестовым wordmark. Отдельная прозрачная маска принята как знак сайта и используется в шапке вместо текстовой буквы «М».

После удаления `npm run lint` и `npm run build` прошли успешно; production-сборка содержит 128 статических страниц и не содержит маршрута `/test-palette`.

## Следствие

На рабочем сайте остаётся только согласованный знак — двухцветная театральная маска. Если позднее появится исходный вектор, PNG можно заменить без изменения структуры шапки.
