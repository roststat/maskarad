# 003-19 — сохранение брифа праздника в PDF

## Задача

По решению владельца выделить возможность сохранить пожелания к празднику в PDF и добавить кнопку скачивания в попап помощника.

## Выполнено

- В пояснении помощника выделена фраза «сохранить себе в PDF» с небольшой иконкой документа.
- Добавлена кнопка «Скачать PDF».
- PDF создаётся на устройстве посетителя из текущего текста в поле пожеланий; используется встроенный шрифт с поддержкой кириллицы.
- В файл входят название театра, заголовок, текст брифа и телефон для связи.
- Если текст ещё не введён, помощник объясняет, что сначала нужно надиктовать или написать пожелания.

## Доказательства

- Браузерная проверка на тестовом русском тексте завершилась статусом «PDF скачан — его можно сохранить себе или отправить в театр.»
- `npm run lint`, `npm run build` и `git diff --check` прошли успешно; production-сборка сформировала 129 статических страниц.
