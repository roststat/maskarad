# 060-5 — Production-доставка в закрытую группу MAX

Дата: 2026-10-12.

Результат одной строкой: **production API сохраняет заявку на российском сервере и доставляет копию в выбранную закрытую группу MAX.**

Владелец создал бота, разрешил его добавление в группы, назначил администратором и утвердил публикацию политики и согласия `2026-10-12-v2`. `MAX_BOT_TOKEN` и `MAX_CHAT_ID` записаны только в закрытый `/opt/maskarad/app/.env.production`; значения не выводились и не попадали в Git. Корневой сертификат Минцифры передан Node через окружение PM2 до запуска процесса, проверка TLS не отключалась.

Доказательства из двух плоскостей:

- публичный `POST /api/leads` с синтетическими данными вернул HTTP `200` и `{"ok":true,"delivery":"max"}`;
- закрытое серверное хранилище содержит синтетические записи с правами `0600`, а предварительная локальная проверка и production-запрос были приняты группой MAX.

Три синтетические записи оставлены в закрытом хранилище: их удаление не выполнялось без отдельного подтверждения владельца. Реальные заявки и секреты при проверках не читались.
