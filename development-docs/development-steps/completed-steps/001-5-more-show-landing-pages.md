# 001-5 — Дополнительные посадочные спектаклей

Дата завершения: 2026-10-03.

## Что сделано

Добавлены отдельные SEO-посадочные для спектаклей из старой карты миграции:

- `/spektakli/belosnezhka-i-sem-gnomov`;
- `/spektakli/mary-poppins`;
- `/spektakli/priklyucheniya-sindbada-morehoda`;
- `/spektakli/malysh-i-karlson`.

Для страниц использованы старые URL и метаданные как источник направления, но тексты написаны заново под современную структуру: первый экран, факты, сценарные блоки, что входит, FAQ, связанные страницы и заявка.

## Редиректы

Добавлены точные постоянные редиректы:

- `/detskii-prazdnik/belosnezhka.html` → `/spektakli/belosnezhka-i-sem-gnomov`;
- `/detskii-prazdnik/mary-poppins.html` → `/spektakli/mary-poppins`;
- `/detskii-prazdnik/sinbad-morehod.html` → `/spektakli/priklyucheniya-sindbada-morehoda`;
- `/detskii-prazdnik/karlson.html` → `/spektakli/malysh-i-karlson`.

## Медиа

Из FTP-архива старого сайта в `public/images/legacy/` добавлены:

- `belosnezhka.jpg`;
- `mary-poppins.jpg`;
- `sinbad-morehod.jpg`;
- `karlson.jpg`.

Часть архивных фото маленькая, поэтому это временный слой визуального доказательства. На этапе визуальной библиотеки стоит заменить слабые изображения более качественными кадрами, если они найдутся в архиве или у владельца.

## Доказательства

- `npm run build` прошел успешно; количество статических страниц выросло до 30.
- Локальный сервер `4311` вернул `200 OK` для всех четырех новых страниц.
- Старые URL вернули постоянный редирект на новые страницы.
- `sitemap.xml` содержит все четыре новых URL.

## Что осталось

- Перенести или осознанно объединить следующие спектакли из старой очереди: `Бременские музыканты`, `Новогодняя Белоснежка`, `Новогодние спектакли`.
- Перейти к сильным услугам из старой карты: `Цирковые фокусы`, `Кукольные спектакли`, `Оформление шарами`.
