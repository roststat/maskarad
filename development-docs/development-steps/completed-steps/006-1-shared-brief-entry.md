# 006.1 — Общий вход в помощника

В `PartyAssistantProvider` поднято одно состояние диалога над шапкой и страницей. Кнопка у логотипа и вход из общего `LeadForm` открывают одно окно; отдельная форма не дублирует помощника.

Доказательство: в браузере production-сборки вход из формы открывает диалог «Конструктор брифа праздника»; `LeadForm` используется в общих CTA на страницах сайта.
