# 003-9 — рабочая форма заявки и первый канал лида

## Задача

Форма заявки была визуальным блоком без действия: кнопка не отправляла данные и не помогала владельцу быстро получить вводные по празднику. Нужно было сделать первый рабочий сценарий без хранения секретов и без подключения внешнего backend.

## Что сделано

- Вынесена клиентская форма `LeadForm`.
- Форма собирает структурированный бриф: имя, телефон, формат, дату, возраст детей, площадку и комментарий.
- При отправке формируется готовое сообщение в WhatsApp на номер театра.
- Добавлена базовая проверка телефона: без контакта форма не открывает канал отправки.
- В форме оставлена альтернативная кнопка звонка.
- Обновлены стили: сетка полей на широком экране, один столбец на мобильном, фокус-состояния, статус заявки и отдельный блок действий.

## Доказательства

- `npm run build` прошел успешно.
- Локальная production-проверка `/spektakli/piraty-karibskogo-morya` вернула `200 OK`.
- HTML страницы содержит `lead-form-grid`, поля `Что планируете`, `Возраст детей`, статус `Заявка откроется в WhatsApp`.
- HTML главной страницы содержит новую форму и статус заявки.

## Следствие

У сайта появился первый реальный путь конверсии: посетитель не просто видит кнопку, а отправляет в театр уже собранные вводные. Следующим шагом можно подключить более надежный канал: email/API, CRM, Telegram-уведомления или Vercel-интеграцию.
