# 004-17 — маркировка материалов и покрытие старых URL

Дата: 2026-10-04

## Цель

Не смешивать реальные кейсы и редакционные материалы, а также проверить, покрыты ли старые URL из инвентаризации редиректами.

## Что сделано

- В шаблон SEO-материалов добавлен блок `content-disclosure`.
- Материалы автоматически получают видимую маркировку:
  - `Гайд` — редакционный материал на основе структуры услуг и опыта театра;
  - `Подборка` — редакционный материал для выбора формата;
  - `Редакционный кейс` — пример структуры праздника, не выдающийся за подтвержденный отчет.
- Добавлены стили для доверительной маркировки в hero материала.
- Расширены редиректы старого сайта:
  - `/maskarad/*`;
  - `/teatr/*`;
  - `/detskii-spektakl/*`;
  - `/news/*`;
  - `/partnery/*`;
  - `/links/*`;
  - `/index.html`, `/error.html`;
  - недостающие старые разделы праздников и медиа.

## Проверка старых URL

Инвентаризация старого сайта содержит `356` уникальных URL.

Из них внутренние URL старого сайта: `163`.

После расширения редиректов:

- покрыто внутренних URL: `163 / 163`;
- точных редиректов: `63`;
- групповых редиректов: `100`;
- внутренних URL без покрытия: `0`.

Остальные URL из общего числа `356` — это внешние партнерские ссылки, YouTube embed, email/служебные строки и другие адреса, которые не должны становиться страницами нового сайта.

## Доказательства

- `npm run build` прошел успешно.
- Скриптовая проверка `urls.csv` против `next.config.ts` показала `internal: 163`, `covered: 163`, `unmatched: 0`.
- Локальные HTTP-проверки старых URL подтвердили постоянные редиректы и финальные страницы:
  - `/maskarad/klienty.html` → `/otzyvy-pressa`;
  - `/teatr/maskarad/contacts.html` → `/kontakty`;
  - `/detskii-spektakl/vinni-puh.html` → `/spektakli`;
  - `/detskie-prazdniki/den-znanii.html` → `/prazdniki`;
  - `/scenarii/detskii-prazdnik-gorod-masterov.html` → `/prazdniki`.
- `curl -L` подтвердил финальные `200 OK` для старых URL со слэшем: `/news/`, `/partnery/list/`, `/maskarad/`, `/teatr/`.
- HTML материалов содержит новые метки: `Редакционный кейс`, `Гайд`, `Подборка`.

## Осталось

- Позже укоротить цепочки редиректов для части URL со слэшем на конце, если это будет критично для SEO-аудита.
- Когда появятся реальные подтвержденные кейсы, добавить отдельную маркировку `Реальный кейс` и источник подтверждения.
