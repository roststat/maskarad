# 007.1 — Бриф вынесен из формы

`CTA` теперь содержит две соседние карточки: заявка с именем и телефоном и личный бриф. Кнопка брифа находится в отдельном `aside`, а не внутри `form`.

Доказательство: DOM главной страницы показывает самостоятельные `form` и `complementary "Бриф праздника для себя"`; этот же `CTA` используется на посадочных.
