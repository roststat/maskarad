# 004-48 — Литературные сценарии: Пушкин и Шехерезада

## Результат

Добавлены два материала на основе самостоятельных старых сценариев:

- `/stati/prazdnik-po-skazkam-pushkina-dlya-detey`;
- `/stati/skazki-sheherezady-scenariy-dlya-detey`.

Они получают точные постоянные редиректы со старых URL. Материалы объясняют подготовку сценария для школы, семейной группы или площадки и не заявляют о подтвержденной доступности конкретной театральной постановки.

## Доказательства

- `npm run seo:predeploy` прошел: покрытие 163 внутренних старых URL, аудит 179 правил, alt, TypeScript и production-сборка 97 статических страниц.
- `npm run seo:migration-relevance` показал 73 широких тематических назначения вместо 75; URL, покрытых только catch-all-правилом, нет.
