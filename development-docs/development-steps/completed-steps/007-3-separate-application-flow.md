# 007.3 — Заявка отдельно от конструктора

Из конструктора удалены поля контакта и прямая отправка в `/api/leads`. После PDF можно перейти к отдельной форме заявки. Голосовой ввод запускается отдельно; перед ним показано предупреждение о возможном сервисе браузера.

Доказательство: браузерный DOM после создания PDF содержит только редактируемый текст, скачивание и кнопку «Перейти к заявке»; переход закрывает окно и прокручивает страницу к заявке. Отдельные карточки проверены на широком и мобильном `390×844` экране.

Публикация: Timeweb записал `64ccf3f` как успешный деплой, PM2 показывает `maskarad-site` online; приложение отдаёт отдельную карточку брифа, а HTTPS с сервера отвечает `200`.
