# 006.2 — Личный PDF перед заявкой

Помощник сначала принимает пожелания и собирает редактируемый бриф. PDF создаётся в браузере без имени и телефона. Поля контакта появляются только после нажатия «Отправить бриф театру». При недоступности OpenAI исходные пожелания остаются черновиком для PDF.

Доказательство: в браузере после подготовки брифа показаны кнопка «Скачать PDF для себя» и отдельная опция отправки; контактных полей нет до выбора отправки. Нажатие скачивания завершилось сообщением «PDF скачан». Автоматическое событие загрузки во встроенном браузере не было доступно для проверки самого файла.
