# 010-2 — счётчик SPA

2026-10-09. Подключён счётчик Яндекс Метрики 113579092 при первом открытии сайта. В клиентском компоненте один раз загружается `tag.js`, инициализация использует `defer: true`, после чего отправляется `hit` для начального пути и при смене пути Next.js. Повторный `hit` для того же пути не отправляется. Параметры URL и заголовок страницы не передаются; `/admin` исключён. Для браузеров без JavaScript добавлен `noscript`-пиксель из кода, предоставленного владельцем.

Настройки владельца `webvisor`, `clickmap`, `trackLinks`, `accurateTrackBounce` сохранены. Поля и блоки заявки помечены `ym-disable-keys`/`ym-hide-content` по официальной инструкции Яндекса, чтобы Вебвизор не записывал введённые имя, телефон и пожелания.

Локальный браузер: на главной до нажатия «Понятно» присутствует один `script` с `tag.js?id=113579092`; уведомление информирует о Метрике. TypeScript и production build прошли.
