# 003-17 — Помощник по празднику в логотипе

## Задача

Сократить основную форму до имени и телефона, а подробности праздника собирать отдельным понятным сценарием.

## Сделано

- В основной форме оставлены только поля «Имя» и «Телефон».
- Двухцветная маска в логотипе стала кнопкой помощника: на ней пульсирует микрофон; фиксированная по размеру подсказка «Расскажите о празднике» печатается под знаком и дополнена мини-эквалайзером. Для неё зарезервирована нижняя зона шапки, поэтому она не пересекает меню и хлебные крошки.
- По нажатию открывается окно с микрофоном внутри поля пожеланий, редактируемым текстом, кнопкой сборки брифа через OpenAI и полями имени/телефона для отправки; клик вне карточки закрывает окно. Карточка имеет безопасный отступ сверху и внутреннюю прокрутку для экранов с небольшой высотой.
- Окно выводится через React Portal непосредственно в `body`, чтобы CSS-размытие закреплённой шапки не создавало для него ограниченный слой и не превращало его в часть меню.
- Если OpenAI ещё не настроен, пожелания всё равно можно отправить без ИИ; секрет остаётся только в `OPENAI_API_KEY` на сервере.
