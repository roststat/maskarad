# 051-1 — Общий механизм начала страницы

2026-10-10. PageStartLink подключён к хлебным крошкам и всем публичным компонентам с Next Link: главная, универсальные каталоги/посадочные/статьи, корпоративная страница, фотогалерея, фотолента, мини-галерея, документы и 404. Меню и логотип используют тот же механизм. Контроллер перенесён в сохраняющийся корневой PageStartProvider: размонтирование исходной карточки или крошек не теряет запрос на сброс прокрутки.

Сброс происходит после перехода без плавной анимации. Внутренние ссылки с #якорем, внешние переходы, открытие в новой вкладке и история браузера не запускают сброс. Сохранено предотвращение перехода в onNavigate.

Доказательства: `npm run lint` и `npm run build` прошли; сверка импортов показывает, что только общий PageStartLink напрямую использует `next/link`, остальные публичные компоненты используют обёртку. Браузер подтвердил `scrollY=0` после карточки каталога.

Результат: поведение 048 расширено на все переходы между страницами через Next Link. Завершён локально.
