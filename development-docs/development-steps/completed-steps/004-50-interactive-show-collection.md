# 004-50 — Подборка интерактивных спектаклей

## Результат

Добавлена подборка `/podboroki/interaktivnye-spektakli-dlya-detey`. Она объясняет, как выбрать спектакль с участием детей по возрасту, площадке и размеру группы, и ведет к каталогу и возрастным материалам.

На подборку перенаправлены четыре старых URL: страницы интерактивных спектаклей, театрализованных игровых программ и выбора спектаклей по возрасту. Это сохраняет общий интент этих страниц без создания неподтвержденных карточек старого репертуара.

## Доказательства

- `npm run seo:predeploy` прошел: покрытие 163 внутренних старых URL, аудит 179 правил, alt, TypeScript и production-сборка 99 статических страниц.
- `npm run seo:migration-relevance` показал 64 широких тематических назначения вместо 68; URL, покрытых только catch-all-правилом, нет.
