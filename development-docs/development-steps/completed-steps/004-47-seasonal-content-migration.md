# 004-47 — Сезонные страницы Масленицы и осенних сценариев

## Результат

Добавлена посадочная `/prazdniki/maslenitsa` для двух активных старых URL о Масленице: страницы праздника и сценария. Архивное фото на странице подписано как иллюстрация формата, потому что отдельного подтвержденного изображения Масленицы в отобранной библиотеке нет.

Добавлены статьи:

- `/stati/detskiy-prazdnik-na-hellouin`;
- `/stati/prazdnik-oseni-dlya-detey`.

Они получают старые URL Хэллоуина, «Сюрпризов осени» и «Царицы осени». Статьи построены как практические материалы; они не заявляют, что соответствующая программа доступна к заказу.

При проверке найдено несовпадение транслитерации в старом адресе `surprisy-oseni`; точное правило исправлено по инвентаризации.

## Доказательства

- `npm run seo:predeploy` прошел: покрытие 163 внутренних старых URL, аудит 179 правил, alt, TypeScript и production-сборка 95 статических страниц.
- `npm run seo:migration-relevance` показал 75 широких тематических назначений вместо 80 и ноль URL, покрытых только catch-all-правилом.
