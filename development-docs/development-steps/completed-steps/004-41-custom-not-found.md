# 004-41. Понятная 404-страница

## Результат

Добавлен `app/not-found.tsx` в существующей визуальной системе. Страница сообщает о проблеме и ведет в главные рабочие маршруты: на главную, в каталог спектаклей и в статьи.

## Доказательство

`npm run lint` прошел успешно. `npm run build` прошел успешно и вывел специальный маршрут `/_not-found`; всего сгенерировано 84 статические страницы.

## SEO-решение

404 не добавляется в sitemap и не создается как контентная посадочная. Она нужна для возврата пользователя в понятный путь после старой ссылки, ошибки в URL или внешнего перехода.
