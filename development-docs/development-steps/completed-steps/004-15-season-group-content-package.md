# 004-15 — пакет материалов про сезон, размер группы и мастер-класс

Дата: 2026-10-04

## Цель

Расширить SEO-портал материалами под частые запросы: праздник зимой, праздник летом, праздник для 10 детей, праздник для 20 детей, праздник с мастер-классом.

## Что сделано

- Добавлены 5 новых SEO-материалов:
  - `/stati/detskiy-prazdnik-zimoy`;
  - `/stati/detskiy-prazdnik-letom`;
  - `/podboroki/prazdnik-dlya-10-detey`;
  - `/podboroki/prazdnik-dlya-20-detey`;
  - `/podboroki/prazdnik-s-master-klassom`.
- Хаб `/stati` получил сезонные материалы про зиму и лето.
- Хаб `/podboroki` получил материалы по размеру группы и празднику с мастер-классом.
- Все новые материалы собраны в текущем шаблоне SEO-портала: `Article`, хлебные крошки, факты, H2-блоки, FAQ, связанные страницы, галерея, рекламные места и блок следующего выбора.

## Доказательства

- `npm run build` прошел успешно; количество статических страниц выросло с `68` до `73`.
- Локальный preview на `http://localhost:4311` вернул `200 OK` для всех 5 новых URL.
- `sitemap.xml` содержит все 5 новых URL.
- HTML хабов `/stati` и `/podboroki` содержит новые teaser-ссылки.
- CDP-проверка viewport `390×844` для `/stati`, `/podboroki` и 5 новых материалов показала `scrollWidth=390`, `bodyScrollWidth=390`, `hasHorizontal=false`.
