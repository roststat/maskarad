# 007-8 — Публикация документов и закрытого хранения заявок

Дата: 2026-10-08. Владелец разрешил проверять VPS и подтвердил регион сервера в России.

## Результат

- Коммит `59818b7` развернул штатный `maskarad-auto-deploy.service` в изолированном контуре `/opt/maskarad/app`; сервис сообщил `success`.
- Вне приложения создан `/opt/maskarad/private/leads` с правами `0700`. Секретный файл конфигурации имеет права `0600`, хэш отдельного пароля проверен без вывода значения.
- Публичные `/privacy-policy`, `/personal-data-consent`, `/cookie-policy`, `/terms` ответили `200`. Админская страница без пароля ответила `401`, с паролем — `200` и `Cache-Control: no-store, private`; тело страницы при проверке не читалось.
- API отклонил заявку без согласия (`400`), принял одну синтетическую заявку (`200`), записал её в файл `0600`; тестовый файл удалён, каталог снова пуст.
- `maskarad-leads-purge.timer` включён и активен. Запуск сервиса удалил только специально созданный пустой просроченный тестовый файл; следующая автоматическая проверка назначена на 2026-10-09.
- Nginx работает через HTTPS; его журналы ротируются ежедневно, сохраняется 14 архивов. Проверка страницы политики не выявила заголовка `Set-Cookie`.

## Осталось оператору

Проверить/подать уведомление Роскомнадзора, утвердить порядок исполнения запросов на удаление и подтвердить сроки резервных копий у Timeweb. По последующему уточнению владельца, ранее заявки в Telegram не получали; предположение об исторических копиях было ошибочным. До оставшихся действий нельзя утверждать полное соблюдение всех обязанностей оператора.

Автоматическая проверка безопасности отклонила попытку загрузить HTML админской страницы при тесте, потому что он мог содержать реальные заявки. Проверка была повторена только по HTTP-статусу и заголовкам, без чтения HTML.
