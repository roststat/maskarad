# 004-53 — Посадочные мультяшных спектаклей

## Результат

Добавлены отдельные посадочные:

- `/spektakli/istoriya-igrushek`;
- `/spektakli/lednikovyy-period`;
- `/spektakli/simpsony`.

Страницы не выдают архивный репертуар за подтвержденное текущее предложение: они объясняют современный формат выбора интерактивной программы, а архивные кадры прямо помечены как иллюстрации.

Три старых URL теперь ведут постоянным точным редиректом на релевантные посадочные вместо общего каталога спектаклей.

Также паспорт проекта обновлен согласно решению владельца: Vercel не используется, финальное размещение состоится на выбранном сервере отдельным шагом.

## Доказательства

- `npm run seo:predeploy` прошел: покрытие 163 внутренних старых URL, аудит 179 правил, alt, TypeScript и production-сборка 108 статических страниц.
- `npm run seo:migration-relevance` показал 52 широких тематических назначения вместо 55; URL, покрытых только catch-all-правилом, нет.
