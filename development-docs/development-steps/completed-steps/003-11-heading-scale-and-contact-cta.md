# 003-11 — уменьшение заголовков и уточнение CTA контактов

## Задача

Владелец отметил, что крупные кнопки смотрятся хорошо, но заголовки слишком большие. Нужно было уменьшить типографический масштаб без потери выразительности и не трогать крупные CTA.

## Что сделано

- Уменьшен базовый масштаб `h1` в hero и section hero.
- Уменьшен мобильный максимум `h1`, чтобы заголовки не занимали слишком много первого экрана.
- Уменьшен масштаб вторых заголовков секций, каталогов и посадочных блоков.
- Расширена допустимая строка для посадочных `h1`, чтобы длинные названия меньше дробились.
- На странице `/kontakty` основной CTA исправлен с `Позвонить` на `Оставить заявку`; звонок остался отдельной кнопкой.

## Доказательства

- `npm run build` прошел успешно.
- `/kontakty` вернул `200 OK`.
- `/spektakli/piraty-karibskogo-morya` вернул `200 OK`.
- HTML `/kontakty` содержит `Оставить заявку`, `Написать`, `mobile-quick-actions` и `lead-form-actions`.

## Следствие

Интерфейс стал спокойнее и ближе к ощущению крупного агентства: кнопки сохраняют заметность, а заголовки меньше спорят с контентом и лучше подходят для мобильного чтения.
