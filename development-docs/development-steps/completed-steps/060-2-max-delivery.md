# 060-2 — Серверная доставка в MAX

Дата: 2026-10-12.

Результат одной строкой: **после сохранения резервной копии API может отправить заявку ботом в закрытый MAX-чат или личный диалог владельца.**

Добавлен изолированный серверный модуль MAX Bot API с закрытыми переменными, таймаутом и отключённым предпросмотром ссылок. Токен передаётся в заголовке авторизации и не попадает в URL, клиент, репозиторий или текст ошибки. Поддержаны закрытый чат и личный диалог. При ненастроенном канале сохраняется прежний серверный приём; при сбое настроенного MAX API отвечает форме, что резервная копия сохранена, но уведомление не доставлено.

Доказательства: `npm run leads:max-test` проверил успешный запрос, чат и личный диалог, лимит сообщения, ошибку ответа и отключённый канал без внешней сети; `npm run lint` прошёл.
