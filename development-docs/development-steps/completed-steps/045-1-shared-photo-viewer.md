# 045-1 — Общий просмотрщик фото

Результат: единый клиентский просмотрщик подключён вокруг main в server layout. Серверные шаблоны и изображения передаются через children, граница client ограничена кнопкой/состоянием попапа.

В попапе нативный dialog/showModal: фокус ограничен диалогом, Escape, заметная кнопка закрытия, свободный фон, возврат фокуса; сохраняются прежние overflow и позиция страницы. Кадр object-fit contain без обрезки; подпись, номер и циклические кнопки/клавиши. Жесты Pointer Events: горизонтальный сдвиг от 45 px с проверкой направления, pointer capture и отменой; вертикальное движение не перелистывает. Полный файл загружается только для открытого кадра.

Доказательства: штатный seo:predeploy прошёл типы/build/alt/редиректы/FAQ 122 URL; исходник app/photo-viewer.tsx. Браузер — 045-3.
