# 004-1 — SEO-фундамент и аудитории в шапке

## Задача

Начать превращение сайта в SEO-портал: добавить технический фундамент для хлебных крошек, schema-разметки, рекламных мест и сделать открытые пункты шапки реальными страницами.

## Что сделано

- Добавлен модуль `app/seo.tsx`:
  - визуальные хлебные крошки;
  - JSON-LD;
  - `WebPage`;
  - `BreadcrumbList`;
  - базовый рекламный слот.
- Шаблон каталогов и посадочных получил хлебные крошки, `WebPage`, `BreadcrumbList` и рекламный слот.
- Созданы три SEO-хаба:
  - `/dlya-detey`;
  - `/dlya-vzroslyh`;
  - `/dlya-biznesa`.
- Верхняя открытая навигация теперь ведет на эти хабы, а не на временные существующие страницы.
- Новые страницы автоматически попали в sitemap через `landingPages`.
- После обнаружения stale-артефакта 404 для `/dlya-detey` выполнена чистая пересборка `.next`.

## Доказательства

- `npm run build` прошел успешно после чистой сборки.
- Количество статических страниц выросло до `43`.
- `curl -I` вернул `200 OK` для:
  - `/dlya-detey`;
  - `/dlya-vzroslyh`;
  - `/dlya-biznesa`.
- `.next/server/app/*.meta` для трех новых страниц показывает статус `200`.
- Локальный `sitemap.xml` содержит `/dlya-detey`, `/dlya-vzroslyh`, `/dlya-biznesa`.
- HTML `/dlya-detey` содержит `Хлебные крошки`, `WebPage`, `BreadcrumbList`, `data-ad-slot`.
- HTML `/spektakli` содержит `Хлебные крошки`, `WebPage`, `BreadcrumbList`, `data-ad-slot`, то есть SEO-фундамент применился и к существующему каталогу.

## Следствие

Сайт получил первый порталный слой: аудитории стали реальными индексируемыми хабами, а шаблоны страниц получили базовую техническую структуру для SEO. Следующий подшаг — расширить контент-модель под статьи, кейсы, подборки и более богатые медиа-блоки.
