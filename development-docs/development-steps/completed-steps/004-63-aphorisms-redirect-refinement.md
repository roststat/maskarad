# 004-63 — Уточнение перехода со страницы детских афоризмов

## Результат

Архивная страница `/scenarii/aforizmy.html` оказалась витриной списка коротких цитат, а не полноценным уникальным материалом. Чтобы не создавать тонкую страницу с непроверенными или чужими цитатами, новый материал не добавлялся.

Вместо общего раздела статей URL теперь ведет постоянным точным редиректом на `/podboroki/scenarii-detskih-prazdnikov`: тематический хаб с практическими маршрутами по сценариям, возрастам и событиям.

## Доказательства

- `npm run seo:predeploy` прошел: покрытие 163 внутренних старых URL, аудит 179 правил, alt, TypeScript и production-сборка 128 статических страниц.
- `npm run seo:migration-relevance` показал 26 широких тематических назначений вместо 27; URL, покрытых только catch-all-правилом, нет.
