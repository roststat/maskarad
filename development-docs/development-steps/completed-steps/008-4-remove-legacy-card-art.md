# 008.4 — Убрана старая иллюстрация карточки

Из карточки короткого запроса удалена иллюстрация документа с отметкой, оставшаяся от отменённого PDF-сценария. Карточка теперь содержит только текстовый призыв, описание короткого запроса и подсказку про диктовку.

Доказательства: `npm run lint`, `npm run build` и `git diff --check` прошли.
