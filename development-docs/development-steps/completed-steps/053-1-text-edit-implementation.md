# 053-1 — Правка текста в существующем окне

2026-10-10. Рядом с микрофоном добавлена «ИИ правка текста». Пустое поле получает уведомление: сначала напишите или наговорите пожелания как получится, без структуры. При обработке повторное нажатие и отправка временно недоступны; ошибка сохраняет пожелания. После успеха доступно «Вернуть исходный текст».

Серверный POST `/api/text-edit` передаёт только пожелания в Responses API, использует прежние переменные подключения и модель gpt-5 по умолчанию. Инструкция требует сохранить факты, даты, числа и ограничения, без выдуманных услуг и цен. Добавлены проверка входа, лимит 1200 символов, таймаут и ограничение частоты. Отдельные имя/телефон не передаются, `store:false`. Политика сайта содержит описание функции.

Доказательства: итоговая `npm run build` успешна; реальные HTTP-проверки невалидного JSON, пустого/длинного текста и чужого Origin возвращают ожидаемые 400/403 в `053-api-validation.json`. Проверки с подменённым ответом сервиса отдельно записаны в `053-route-check.json` — семь сценариев прошли.

Результат: существующий попап получил простую правку текста и возврат оригинала; большой ИИ-бриф не возвращён.
