# Подшаг 008-7 — Улучшение изображений карточек спектаклей

## Результат

Для 11 уникальных фотографий спектаклей созданы отдельные улучшенные версии: увеличено разрешение, снижены JPEG-артефакты, аккуратно усилены резкость, контраст и цвет. Исходные файлы сохранены без изменений.

Карточки и страницы спектаклей используют улучшенные версии изображений. Добавлен блок фотографии на карточках каталога, подпись группы и ссылка «Смотреть спектакль →».

## Доказательства

- `npm run lint` — успешно.
- `npm run build` — успешно, 128 статических страниц.
- `git diff --check` — без ошибок.

## Ограничение

Для очень маленьких архивных исходников улучшение техническое и не восстанавливает отсутствующие детали; генеративное восстановление не использовано, чтобы не менять лица и содержание фотографий.
