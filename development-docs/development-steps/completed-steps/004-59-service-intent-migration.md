# 004-59 — Миграция конкретных сервисных интентов

## Результат

Добавлены отдельные посадочные:

- `/uslugi/pozdravitelnaya-pesnya`;
- `/uslugi/detskiy-tort`;
- `/uslugi/shou-s-zhivotnymi`.

Старые URL поздравительной песни, детских тортов и дрессированных животных получили постоянные точные редиректы на новые страницы.

Страница формата с животными не заявляет неподтвержденную доступность: она требует отдельной проверки документов исполнителя, условий площадки, безопасности детей и благополучия животных; предусмотрены альтернативы без животных.

## Доказательства

- `npm run seo:predeploy` прошел: покрытие 163 внутренних старых URL, аудит 179 правил, alt, TypeScript и production-сборка 124 статических страниц.
- `npm run seo:migration-relevance` показал 35 широких тематических назначений вместо 38; URL, покрытых только catch-all-правилом, нет.
