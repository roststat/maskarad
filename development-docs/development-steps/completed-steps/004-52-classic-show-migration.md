# 004-52 — Посадочные классических спектаклей

## Результат

Добавлены отдельные посадочные:

- `/spektakli/zolotoy-klyuchik`;
- `/spektakli/kot-leopold`;
- `/spektakli/tri-mushketera`.

Каждая страница описывает сценарий выбора формата для современного праздника. Использованные архивные изображения прямо обозначены как иллюстрации, а не как фотографии конкретных постановок.

Три соответствующих старых URL теперь ведут постоянным точным редиректом на свои посадочные, а не в общий каталог спектаклей.

## Доказательства

- `npm run seo:predeploy` прошел: покрытие 163 внутренних старых URL, аудит 179 правил, alt, TypeScript и production-сборка 105 статических страниц.
- `npm run seo:migration-relevance` показал 55 широких тематических назначений вместо 58; URL, покрытых только catch-all-правилом, нет.
