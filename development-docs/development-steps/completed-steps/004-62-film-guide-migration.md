# 004-62 — Гайд о съемке фильма с детьми

## Результат

Добавлена статья `/stati/semka-filma-s-detmi-na-prazdnike`. Она сохраняет самостоятельный поисковый интент архивной страницы о съемке фильма с детьми и дает практическую пользу: как упростить сценарий, распределить роли, сохранить добровольность участия и заранее согласовать съемку, хранение и публикацию материалов.

Старый URL `/detskie-prazdniki/film.html` теперь ведет постоянным точным редиректом на эту статью. Материал добавлен в хаб `/stati`, поэтому на него ведет и внутренняя навигация.

## Доказательства

- `npm run seo:predeploy` прошел: покрытие 163 внутренних старых URL, аудит 179 правил, alt, TypeScript и production-сборка 128 статических страниц.
- `npm run seo:migration-relevance` показал 27 широких тематических назначений вместо 28; URL, покрытых только catch-all-правилом, нет.
