# 004-39. Runbook перед деплоем

## Результат

В `README.md` зафиксирован единый порядок входа в проект и подготовки публикации:

- запуск `scripts/server/sync-check.sh`;
- чтение паспорта и текущего шага;
- локальная проверка `npm run seo:predeploy`;
- внешний smoke-test открытого preview через `npm run seo:prelaunch -- <url>`;
- требование не хранить секреты в репозитории;
- отдельная настройка fallback-каналов формы вместе с CRM, без расчета на WhatsApp в РФ.

## Доказательство

`git diff --check` не обнаружил ошибок форматирования; runbook доступен в корневом `README.md`.

## Ограничение

Внешняя проверка Vercel preview не завершена: текущий preview недоступен для автоматического запроса или закрыт защитой Vercel. До публикации нужно открыть preview штатным способом и прогнать `seo:prelaunch`.
