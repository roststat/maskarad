# 003-12 — понятнее интерфейс каталогов и шапки

## Задака

После сравнения с крупным агентским сайтом нужно было усилить ощущение управляемого интерфейса: не просто список страниц, а понятный путь выбора праздника. При этом нельзя копировать чужой дизайн; нужно адаптировать принцип под театр «Маскарад».

## Что сделано

- Добавлен активный пункт основного меню через `HeaderNav`.
- В шапку добавлена отдельная кнопка `Заявка`, чтобы действие было доступно без поиска формы.
- На каталогах быстрые маршруты подняты выше карточек: пользователь сначала выбирает сценарий, потом смотрит направления.
- Добавлен заголовок блока карточек `Популярные направления`, чтобы список не начинался резко после цифр.
- Блок быстрых маршрутов визуально собран в отдельную панель с фоном, рамкой и компактными карточками.
- Сохранены крупные CTA-кнопки и уменьшенная типографика заголовков из предыдущего подшага.

## Доказательства

- `npm run build` прошел успешно.
- `/spektakli` вернул `200 OK`.
- HTML `/spektakli` содержит `aria-current="page"`, `Заявка`, `Быстрый выбор`, `Популярные направления`, `catalog-related`, `listing-heading`.
- HTML `/uslugi` содержит активный пункт меню, `С чем соединить услуги`, `Популярные направления`, `Собрать программу`, `listing-heading`.

## Следствие

Каталоги стали ближе к интерфейсу сильного агентства: сверху есть ориентация, быстрые сценарии выбора, затем каталог. Это снижает ощущение хаотичного SEO-списка и поддерживает образ большой команды.
