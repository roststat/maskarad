# 004-7 — пакет материалов про школьный возраст

## Задача

Продолжить наращивание SEO-портала материалами, которые закрывают разные кластеры спроса: возраст ребенка и площадку проведения праздника.

## Что сделано

- Добавлена подборка `/podboroki/prazdniki-dlya-detey-8-10-let`.
- Добавлена статья `/stati/prazdnik-v-shkole-kak-sobrat-programmu`.
- Обе страницы созданы сразу в расширенной модели:
  - авторская заметка;
  - галерея;
  - блок `Что выбрать дальше`;
  - рекламный слот в середине материала;
  - отдельная метка рекламного места в sidebar;
  - `Article` и `BreadcrumbList` schema через общий шаблон.
- Хабы `/stati` и `/podboroki` получили ссылки на новые материалы.

## Доказательства

- `npm run build` прошел успешно.
- Количество статических страниц выросло с `53` до `55`.
- Локальный production-preview перезапущен на `http://localhost:4311`.
- `curl -I http://127.0.0.1:4311/podboroki/prazdniki-dlya-detey-8-10-let` вернул `200 OK`.
- `curl -I http://127.0.0.1:4311/stati/prazdnik-v-shkole-kak-sobrat-programmu` вернул `200 OK`.
- `sitemap.xml` содержит оба новых URL.
- HTML страницы 8-10 лет содержит `Article`, `BreadcrumbList`, `Главная разница с дошкольниками`, `article-gallery`, `ad-mid-content-page`, `article-next`.
- HTML статьи про школьный праздник содержит `Article`, `BreadcrumbList`, `Не перегружать расписание`, `article-gallery`, `ad-mid-content-page`, `article-next`.

## Следствие

Портал начал закрывать отдельный школьный кластер: возраст 8-10 лет и школьную площадку. Дальше логично добавить выпускной, Новый год, аниматоров на дом и возрастные/сезонные подборки, постепенно усиливая внутреннюю перелинковку.
