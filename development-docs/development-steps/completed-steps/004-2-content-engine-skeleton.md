# 004-2 — каркас статей, кейсов и подборок

## Задача

Запустить контент-машину без раздела “блог”: сделать технический каркас для ежедневного добавления статей, кейсов и подборок под SEO-запросы.

## Что сделано

- Добавлен `app/content-data.ts` с отдельной моделью:
  - хабы материалов;
  - статьи;
  - кейсы;
  - подборки.
- Созданы хабы:
  - `/stati` — в интерфейсе “Идеи и кейсы”;
  - `/kejsy`;
  - `/podboroki`.
- Созданы первые материалы:
  - `/stati/kak-vybrat-spektakl-na-den-rozhdeniya`;
  - `/kejsy/piratskiy-den-rozhdeniya-7-let`;
  - `/podboroki/spektakli-dlya-5-7-let`.
- Для материалов добавлен шаблон с:
  - хлебными крошками;
  - hero;
  - датами публикации и обновления;
  - фактами;
  - основным текстом;
  - боковым блоком связанных страниц;
  - рекламным слотом внутри текста;
  - рекламным слотом в sidebar на desktop;
  - FAQ;
  - CTA.
- Добавлена `Article` schema для материалов.
- Sitemap расширен на хабы и материалы.
- В полное меню добавлен пункт `Идеи и кейсы`.

## Доказательства

- `npm run build` прошел успешно.
- Количество статических страниц выросло до `49`.
- `curl -I` вернул `200 OK` для:
  - `/stati`;
  - `/kejsy`;
  - `/podboroki`;
  - `/stati/kak-vybrat-spektakl-na-den-rozhdeniya`.
- Локальный `sitemap.xml` содержит `/stati`, `/kejsy`, `/podboroki` и три первых материала.
- HTML первой статьи содержит `Article`, `BreadcrumbList`, `Хлебные крошки`, `data-ad-slot`, дату публикации.
- HTML `/stati` содержит карточки первого гайда, кейса и подборки.

## Следствие

Теперь ежедневная публикация может идти через один структурированный файл данных. Следующий подшаг — расширить модель под более богатые галереи, авторские заметки, блоки “что выбрать дальше” и начать выпуск второго пакета материалов по возрастам, площадкам и корпоративным запросам.
