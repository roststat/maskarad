# current-steps.md — состояние проекта между сессиями

Этот файл читается первым после проверки свежести. Он не хранит историю всего проекта, а отвечает на вопрос: где работа сейчас и что делать дальше.

## Текущая работа

Продолжаем SEO-миграцию старого сайта `maskarad-teatr.ru` в современный сайт детского выездного театра «Маскарад» на Next.js.

Фокус ближайшего этапа: не копипаст, а перенос поисковой ценности через инвентаризацию старых URL, отдельные посадочные страницы, точные 301-редиректы, sitemap и проверку production-сборки.

## Следующее действие

Следующий рабочий блок выбрать по ситуации:

1. дождаться переноса DNS `maskarad-teatr.ru` и `www.maskarad-teatr.ru` на текущий сервер, затем добавить изолированный Nginx-виртуальный хост и TLS для `maskarad-site`;
2. до публичного включения продолжать локальную содержательную миграцию по отчету `npm run seo:migration-relevance`, отделяя самостоятельные старые темы от служебных URL и неподтвержденного архивного репертуара;
3. после настройки публичного домена повторить `npm run seo:predeploy`, внешний `seo:prelaunch` и HTTP smoke-test основных 308;
4. после появления подтвержденных реальных кейсов добавить отдельную маркировку `Реальный кейс` и источник подтверждения.
