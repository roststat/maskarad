# development-docs — эволюционирующая память проекта

Здесь живут документы, которые агент ведёт по ходу работы. Это не свалка справок, а память проекта.

## Три рода знания

| Род знания | Где живёт | Почему |
|---|---|---|
| Закон | `AGENTS.md` | действует всегда и читается в начале |
| Состояние | `development-steps/current-steps.md` | показывает, где работа сейчас |
| Опыт | эта папка | появляется после ошибок, решений и проверок |

## Что здесь по праву

| Документ | Когда обновляется |
|---|---|
| `PASSPORT.md` | изменилось понимание проекта, принято решение владельца, проверена гипотеза |
| `development-steps/` | план, текущее состояние и итоги работ |
| `reports/` | законченная фича или большой отказ |
| `ANTI-PATTERNS.md` | найден подход, который нельзя повторять |
| `GLOSSARY.md` | появился термин, важный больше чем в одном месте |
| `BACKLOG.md` | возник долг, который не входит в текущий шаг |
| `CANCELLED.md` | решение отменено и не должно воскреснуть по памяти |
| `TRANSLATION-DEBT.md` | появились тексты не на всех нужных языках |

## Главное правило

Документ отвечает на один вопрос. Паспорт не становится журналом работ, current steps не становится паспортом, anti-patterns не становится отчётом.
