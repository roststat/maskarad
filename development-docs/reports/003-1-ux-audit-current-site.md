# 003-1 — UX-аудит текущего нового сайта

Дата: 2026-10-02.

## Вывод

Новый сайт уже имеет правильное направление: театр, выездной формат, SEO-посадочные и заявка. Главная проблема текущей версии — пользователь с телефона должен слишком рано разбираться в каталоге. Для конверсии лучше вести его через задачу: день рождения, детский сад, школа, выпускной, спектакль или услуга.

## Главные проблемы

| Экран | Проблема | Решение |
|---|---|---|
| Главная | После первого экрана были только общие разделы: спектакли, услуги, праздники | Добавлен блок быстрого выбора по задачам с переходами на сильные посадочные |
| Главная | Карточки направлений вели на общие разделы и не усиливали новые SEO-страницы | Внутри карточек добавлены ссылки на конкретные посадочные |
| Header mobile | Навигация могла занимать слишком много высоты из-за переносов | На планшете/мобиле навигация стала горизонтально прокручиваемой |
| Посадочные | Есть структура, но пока мало визуального доверия и реальных фото по темам | Следующий подшаг: выбрать и подключить фото из FTP-архива |
| Форма | Форма визуально есть, но канал доставки заявки еще не согласован | Отдельный подшаг: подключить доставку лидов |

## Что уже изменено

- На главную добавлен блок `Быстрый выбор`: день рождения, детский сад, школа, выпускной.
- Карточки `Спектакли`, `Услуги`, `Праздники` теперь ведут не только в общий каталог, но и на конкретные SEO-посадочные.
- Мобильная навигация в header переведена в горизонтальную прокрутку.
- Стили разделены так, чтобы ссылки внутри списков не превращались в лишние крупные кнопки.

## Следующие дизайн-приоритеты

1. Подключить реальные фото из FTP-архива к главной и посадочным.
2. Усилить шаблон SEO-посадочной: доверие, фото, форматы, CTA, FAQ.
3. Сделать работающую форму заявки и быстрый мобильный контакт.
4. Проверить мобильные экраны в браузере: главная, каталог, посадочная, контакты.
5. Убрать статические 404 вроде favicon, если они повторяются в локальном сервере.
