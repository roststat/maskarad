# 078 — Карта сайта для посетителей

17 октября 2026. Решение владельца: «Да, отлично давай сделаем. И нужно гдето зафиксировать чтобы эту страницу обновлять с появлением новых страниц».

Создана `/karta-sayta` со ссылкой в общем подвале: основные разделы, праздники, спектакли, услуги, статьи, кейсы, подборки и документы. 125 индексируемых URL и четыре юридических документа. Ссылки доступны в серверном HTML; закрытые страницы не показываются, noindex документов сохранён.

Список индексируемых URL берётся из генератора sitemap.xml. Каталоги и материалы включаются автоматически при следующей сборке и публикации. Новые отдельные маршруты требуют URL и названия по правилу в README и AGENTS.md. Проверка `seo:html-sitemap` включена в штатный gate и обнаруживает пропуски в картах.

Доказательства: полный SEO gate успешен; намеренно пропущенная новая индексируемая страница остановила проверку. Браузер 1280×900 и 390×844, две/одна колонки без горизонтального переполнения, якорь документов и переход из подвала проверены. Проверка полноты покрывает статические страницы; при появлении динамических публичных URL её нужно расширить.

Опубликована версия приложения `5671549` через origin/main и штатный автодеплой. Серверные HEAD и маркер совпали, systemd Result=success, PM2 online. Публично карта — 200, 129 уникальных ссылок; XML — 125 URL с картой, ссылка в подвале главной присутствует. Внешний SEO smoke-test 12/12, публичный браузер подтвердил страницу.
