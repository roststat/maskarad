# 080 — Основной домен и старый адрес карты сайта

23 октября 2026. Разрешение владельца: «Осталось два полезных улучшения: настроить постоянный переход с `www` на основной домен и направить `/karta.html` прямо на новую карту сайта. делай».

## Результат

- HTTPS www теперь отвечает постоянным 308 на HTTPS non-www с сохранением пути и query.
- HTTP обоих имён отвечает 301 прямо на HTTPS non-www.
- `/karta.html` при HTTP/HTTPS и www/non-www ведёт одним 308 прямо на `/karta-sayta`, сохраняя параметры.
- Основное приложение сохраняет прежнее проксирование на 127.0.0.1:3200. Конфигурация сертификата для обоих имён сохранена.

Версия приложения `26ecfbcc84d6c21fcde294333321ad4c70865036` опубликована через штатный автодеплой. Серверные HEAD/маркер совпали, Result=success. Конфигурация Nginx сохранена в репозитории, установка выполняется отдельно скриптом с резервной копией, проверкой и откатом. Резервная копия действовавшего файла: `/opt/maskarad/deploy-backups/maskarad-nginx-20261023T114523Z-888205.conf`.

## Доказательства

Полный seo:predeploy успешен локально и на сервере. Nginx -t до и после изменения, reload успешен. PM2 maskarad-site, maxflok-site и процессы Fractera online. Изменён только virtual host Маскарада; прежние предупреждения в других Nginx-конфигах остались вне области работы.

Публичная [матрица](080-public-redirect-matrix.json) прошла 28/28: четыре origin, сохранение UTM/кодированных/пустых параметров, прямой переход старой карты, TLS, 200 конечных страниц и 404 неизвестного пути.
