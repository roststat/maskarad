# 042 — Живые фотографии по сайту

9 октября 2026. Результат проверен в локальном просмотре на порту 4310, на production не опубликован.

## Что сделано

- Учтены все 104 предоставленных владельцем файла, подготовлены 102 разных WebP. Два точных дубля используют один соответствующий файл. Исходники владельца сохранены без изменений.
- На корпоративной странице 18 разных фото: первый экран, карточки преимуществ, состав программы, площадка, реквизит, галерея и финальный блок предложения. Прежняя общая тройка заменена.
- На `/foto-video` полная подборка с четырьмя тематическими фильтрами, постепенным показом по 24, открытием кадра крупнее и переходами к соответствующим программам. Первые кадры показывают детей, участие в спектаклях и шоу.
- На 16 тематических страницах и их карточках — соответствующие героям/услугам фото. Общие галереи используют новые фотографии, первый экран главной обновлён.
- Подписи описывают кадры; названия корпоративных клиентов, даты, размер мероприятий и вымышленные отзывы не добавлены. Фактура для самостоятельных реальных корпоративных кейсов остаётся отдельной задачей.

## Проверка

Штатный `seo:predeploy` прошёл типы/сборку, alt, покрытие старых URL, редиректы и FAQ 122 страниц. После визуальных поправок финальная сборка прошла повторно. Локальный smoke-test — 12/12. Все 102 изображения декодируются и доступны по HTTP 200 с типом WebP. Размер подготовленной подборки 16,19 МБ вместо исходных 36,7 МБ; изображения вне первого экрана загружаются лениво, размеры зарезервированы, используются адаптивные варианты Next Image.

В браузере проверены desktop 1280/mobile 390, отсутствие горизонтальной прокрутки, видимость кнопки предложения, фильтры, раскрытие всех 102 фото и тематическая страница «Смурфики». Полноценный замер Web Vitals в production не выполнялся.
