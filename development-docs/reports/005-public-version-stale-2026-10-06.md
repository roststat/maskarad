# Отставание публичной версии — 2026-10-06

## Симптом

Локальный и серверный `HEAD` совпадали с `origin/main` на `f9345c9`, но домен показывал старую шапку, а новый `/api/party-brief` возвращал `404`. Обычный healthcheck и `seo:prelaunch` проходили: они проверяли доступность и SEO-ответы, а не свежесть сборки.

## Подтвержденная причина

На VPS Timeweb `.next/BUILD_ID` был создан 2026-10-05. Журнал `maskarad-auto-deploy.service` показал, что после `git reset --hard f9345c9` команда `tsc --noEmit` остановилась на старом сгенерированном `.next/types/validator.ts`, где оставалась ссылка на удаленный `/test-palette/page.js`. Скрипт проверял только совпадение Git-коммитов; после неудачного gate последующие вызовы таймера завершались без сборки и перезагрузки.

## Восстановление

На сервере удалены только устаревшие `.next/types`, затем `npm run seo:predeploy` прошел полностью и перезагружен только PM2-процесс `maskarad-site`. Новый `.next/BUILD_ID` — `1Xm5cJjs41-UwcpcZfp5Q`. Публичная главная показывает «Театр праздника», GET `/api/party-brief` возвращает `405` как существующий POST-маршрут, внешний `npm run seo:prelaunch -- https://maskarad-teatr.ru` прошел `12/12`.

## Защита от повтора

В `scripts/server/auto-deploy.sh` добавлен маркер последнего успешного деплоя, который записывается только после сборки и `pm2 reload`. Перед TypeScript-проверкой удаляются устаревшие сгенерированные типы; отсутствие `.next/BUILD_ID` требует повторной сборки. Локальный тест моделирует неуспешную перезагрузку, повторную попытку и исчезновение сборки. На сервере после обновления скрипта сервис выполнил полный gate и записал маркер `bc5eb67`, совпадающий с `HEAD`.
