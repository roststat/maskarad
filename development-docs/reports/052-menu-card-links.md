# 052 — Клик по карточке меню открывает общий раздел

10 октября 2026. По запросу владельца свободная область карточки открытого меню теперь ведёт на главную страницу соответствующего блока. Например, карточка «Праздники» открывает `/prazdniki`; для перехода в «День рождения» нужно нажать на его название.

## Реализация

Существующая ссылка заголовка покрывает карточку через CSS. Ссылки пунктов занимают ширину названия и располагаются поверх неё; сохранён вертикальный отступ для касания. При наведении пункт подчёркивается. Это обычные ссылки, без вложенных ссылок и без клика на section. Фокус ссылки раздела обводит карточку.

Поведение действует для меню детей, взрослых и бизнеса. Состав и адреса меню, общие отступы сайта, попапы и SEO-даты не изменены. Закрытие меню и открытие страницы с начала используют прежний PageStartLink.

## Проверки

- `npm run build` прошёл с проверкой TypeScript.
- [Браузерный протокол](052-menu-browser.json): свободное место всех 12 карточек desktop имеет адрес раздела; ссылки пунктов ограничены названием.
- Desktop: свободное место «Праздников» → `/prazdniki`, название «День рождения» → `/prazdniki/detskiy-den-rozhdeniya`.
- Mobile 390×844: свободное место → `/prazdniki`, название «Для детского сада» → `/prazdniki/detskiy-sad`; горизонтального переполнения нет.
- Во всех проверенных переходах меню закрывается и scrollY=0.
- Скриншоты: [desktop](052-menu-desktop.png), [mobile](052-menu-mobile.png).
