# 046 — Мини-галерея открывается внутри страницы

9 октября 2026. По уточнению владельца миниатюры под hero больше не переводят в полный раздел. Каждый кадр использует существующий попап 045, открывает нужный индекс и позволяет листать только подборку текущего URL из трёх–четырёх фото. Закрытие возвращает фокус/позицию; адрес страницы не меняется. Самостоятельная текстовая ссылка «Все фотографии» сохраняется.

## Проверка

Штатный SEO gate/типы/build/FAQ успешен. HTML: все 122 URL имеют 3–4 кнопки попапа, изображения не находятся в ссылках; 122 разных набора, положение после hero и ссылка полного раздела сохранены. [Покрытие](046-mini-gallery-coverage.json).

Браузер: corporate desktop 3/4→4/4→1/4, неизменный URL, восстановление фокуса и scrollY; mobile 390×844 на странице с тремя кадрами 3/3→1/3, закрытие, сетка 175/175/358 без переполнения. [Результаты](046-mini-popup-browser.json), [mobile](046-mini-popup-mobile.jpg). Нативный drag проверил общую ветку Pointer Events; физическое сенсорное устройство не использовалось.
