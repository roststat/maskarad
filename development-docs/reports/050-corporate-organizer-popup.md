# 050 — Корпоративная заявка в существующем попапе

10 октября 2026. Уточнение владельца: «У нас уже есть попап не нужно его делать, просто добавь туда все что говорил ранее».

## Что изменилось

Существующий попап «Написать организатору» получил корпоративный выбор гостей: до 100, до 250–300, 300–500, более 500 и «Пока не знаю — обсудим». Это общее число гостей, включая взрослых; число и возраст детей уточняются отдельно. Вариант 300–500 не объявлен отдельным тарифом или программой.

Кнопки предложения, индивидуального расчёта и нижняя мобильная кнопка открывают это окно. Три карточки блока «Под масштаб вашей компании» открывают его с соответствующим числом гостей. Подсказка и пример пожеланий отражают выбор; введённый текст сохраняется при изменении количества. На карточках нет «Выбрать этот масштаб»/«Выбрано».

На странице осталась форма имени и телефона с кнопкой «Отправить заявку», без выбора количества и строки «Ваш запрос: Масштаб…». Обычный режим попапа на других страницах сохранён. Корпоративный контекст и число гостей добавляются в поле `message` существующей заявки. API и хранение заявок не менялись.

## Проверка

- `npm run lint` и `npm run build` прошли.
- `npm run seo:faq-coverage`: 122/122 URL, видимые FAQ совпадают с JSON-LD.
- [Браузерный протокол](050-popup-browser.json): один существующий диалог, все три предвыбора, подсказки, сохранение пожеланий, Escape/Tab, простая форма страницы, мобильная кнопка и обычный попап на странице спектакля. Mobile 390×844 без горизонтального переполнения.
- [Состав сообщения](050-message-check.json): все пять вариантов передают число гостей и пожелания; обычное сообщение не меняется.
- Скриншоты: [desktop](050-popup-desktop.png), [mobile](050-popup-mobile.png).

Сетевую отправку и диктовку не запускали, заявки не записывали. Доставка и кабинетные цели требуют отдельной проверки в рамках 039-5/7.
