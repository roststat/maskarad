# 086 — скорость загрузки

1 ноября 2026. Поручение владельца: «Остаются задачи по скорости сайта реши плиз». Продолжение производительной части 025-3; прежняя оптимизация маски 025-2 не повторялась.

## Что исправлено

- Устранён сдвиг main после hydration: CSS резервирует хлебные крошки из исходного HTML, JS больше не добавляет отступ позднее.
- 43 портретных фото мини-галереи имеют отдельные производные с хешем и тем же ориентиром кадрирования; popup/полная галерея сохраняют оригиналы. Зимняя contain-подборка не кадрируется.
- Hero главной и корпоративной, а также статьи используют качество 65; у статьи задан реальный responsive sizes и актуальный preload вместо deprecated priority. Нужные изображения не скрывались и не удалялись.
- Для хешированных миниатюр включён годовой кеш. При изменении исходника/параметров создаётся новый URL, поэтому кеш не блокирует обновление.
- Повторный trace обнаружил поздний LCP уведомления об аналитике: теперь тот же текст приходит в серверном HTML, а сохранённое закрытие учитывается после hydration. Уведомление не скрывается/не откладывается ради метрик; при полном открытии страницы у ранее закрывшего пользователя оно может кратко появиться до чтения настройки, затем исчезает. Для нижних иллюстраций задан low fetch priority; у статьи сохранена ранняя загрузка через актуальный preload с responsive sizes.

Проверка одинаковых Next Image запросов: портретные mini photo-063 37 306 → 16 386 байт (−56%), photo-076 43 412 → 16 280 (−62%). Hero главной 48 486 → 42 640; корпоративной 76 846 → 68 396. [Точные ответы](086-image-delivery-check.json), [43 производные](086-mini-thumbnails.json).

Финальный повтор выполнен на успешно опубликованном 46e2bfd.
