# FAQ на всех URL sitemap

Выполнена локальная реализация решения владельца «Все 122 страницы»: пять видимых вопросов и ответов на каждом URL sitemap и соответствующий `FAQPage` JSON-LD из того же массива. Для материалов ответы основаны на уже опубликованных разделах; для каталогов и хабов написаны ответы по текущему содержимому страниц.

Проверка: полный `npm run seo:predeploy` успешен; `seo:faq-coverage` сверил 122 prerendered HTML-файла, точное совпадение всех 610 видимых пар с JSON-LD. После публикации `e60fc44` публичные `/spektakli`, `/spektakli/zolushka` и `/stati/kak-vybrat-spektakl-na-den-rozhdeniya` показали по пять видимых пар и пять элементов в одном `FAQPage`; внешний `seo:prelaunch` прошёл 12/12.

Это техническое расширение FAQ не подменяет календарный шаг 009 и не изменяет `lastModified` или `updatedAt` без отдельной содержательной актуализации фактов.
