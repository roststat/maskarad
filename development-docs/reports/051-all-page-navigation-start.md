# 051 — Крошки и карточки открывают начало страницы

10 октября 2026. Исправление по сообщению владельца: «Переходы через меню и по логотипу теперь открывают страницу сверху, без обрезанного хиро. //  через меню поправил, осталось что также режет при переходах по хлебным крошкам и через карточки на страницах и».

## Изменение

Единое правило PageStartLink подключено ко всем публичным переходам через Next Link: хлебные крошки, карточки главной/каталогов/посадочных/статей, связанные программы, переходы в галерею и документы. Меню и логотип сохранены. Контроллер сброса прокрутки находится в корневом layout и переживает исчезновение исходной карточки/крошек. Новая страница открывается с начала документа без анимации прокрутки.

Ссылки с #якорем сохраняют прокрутку к нужному разделу. История браузера и открытие новой вкладки не запускают сброс. Корпоративный попап, фотографии и отступы не менялись.
