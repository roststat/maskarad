# 006 — Бриф праздника для себя

Посетитель может открыть помощника из любой быстрой формы или из знака в шапке, написать либо надиктовать пожелания, отредактировать результат и сохранить PDF. Контакты не нужны для получения файла. После готового брифа отдельно предлагается отправить его театру для подбора программы.

Вход в форме оформлен как спокойный дополнительный путь с иллюстрацией PDF и зелёным микрофоном. Быстрая заявка по имени и телефону остаётся главным действием формы.

Проверка: TypeScript и production-сборка прошли; браузер показал последовательность создания брифа и состояние успешного скачивания без контактных полей. Содержимое скачанного файла во встроенном браузере автоматически не проверялось. Timeweb развернул `0da6319`, PM2 показывает `maskarad-site` online, публичная главная содержит новый блок.
