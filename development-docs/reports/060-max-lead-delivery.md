# 060 — Доставка заявок в MAX

Дата завершения: 2026-10-12.

Обе формы сайта используют единый `/api/leads`. API сначала создаёт закрытую серверную копию заявки, затем отправляет уведомление ботом в закрытую группу MAX. Если MAX временно недоступен, сохранённая копия остаётся на сервере, а интерфейс не сообщает ложный успех доставки.

Токен и ID группы находятся только в `.env.production` на VPS. Официальный корневой сертификат Минцифры подключён к Node-процессу через `NODE_EXTRA_CA_CERTS`; системное хранилище macOS не менялось и проверка TLS не отключалась. Политика и согласие версии `2026-10-12-v2` описывают передачу ООО «МАХ» и были явно утверждены владельцем.

Проверки: контракт MAX без внешнего запроса, TypeScript, production build на 198 страниц, юридический и SEO predeploy, синтетическое сообщение в группе, публичный API `200` с `delivery: max`, серверные файлы заявок с режимом `0600`. Коммиты приложения опубликованы штатным автодеплоем; production-процесс `maskarad-site` перезапущен и сохранён в PM2.

Открытые обязанности вне этого шага: проверить статус уведомления Роскомнадзора и сроки резервных копий Timeweb. Три синтетические production-записи можно удалить после отдельного подтверждения владельца.
