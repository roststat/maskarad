# Яндекс Метрика 113579092

Счётчик опубликован для Next.js App Router по способу SPA. При входе загружается `tag.js` и отправляется первый просмотр; при смене пути отправляется отдельный `hit` без параметров URL. Сохранены выбранные настройки Вебвизора, карты кликов и ссылок. Поля заявки и окно запроса скрыты от записи содержимого.

Cookie-уведомление и политики теперь описывают немедленную загрузку Метрики; кнопка «Понятно» закрывает уведомление, не выдаётся за согласие. Без JavaScript работает `noscript`-пиксель. Публичная проверка в отладчике Яндекса показала просмотры `/` и `/spektakli`; SEO smoke-test — 12/12.

По прямому решению владельца правовое основание немедленного сбора рассматривается отдельно. Это открытый пункт в `BACKLOG.md`; публикация счётчика не означает, что юридическая оценка завершена.
