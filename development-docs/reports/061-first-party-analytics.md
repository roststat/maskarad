# 061 — Собственная серверная аналитика

## Результат

На production работает независимый first-party счётчик для `maskarad-teatr.ru`. Яндекс Метрика 113579092 не удалена и не изменена: оба контура работают параллельно.

Собственный контур измеряет:

- сессии текущих вкладок и просмотры путей без query;
- активное время только при видимой вкладке и недавнем действии;
- домен внешнего источника и очищенные `utm_source`, `utm_medium`, `utm_campaign`;
- тип устройства без сохранения полного User-Agent;
- открытие/результат заявки, выбор корпоративного формата и переход к контакту.

Он не записывает содержимое форм, имя, телефон, полный URL/referrer, полный IP, полный User-Agent, координаты, движение мыши или запись экрана. События идут только в same-origin `/api/analytics`; сбой аналитики не влияет на страницу или заявку.

## Хранение и доступ

Production по умолчанию использует `/opt/maskarad/private/analytics`, вычисленный рядом с существующим `LEAD_STORAGE_DIR`. Каталог создаётся `0700`, дневные файлы — `0600`. Исходные файлы удаляются через существующий ежедневный timer после 180 дней.

Отчёт `/admin/analytics` закрыт тем же Basic Auth владельца, что заявки. Доступны периоды 7/30/90 дней, карточки итогов, дневная динамика, страницы, источники, устройства и цели. Административные страницы не отслеживаются.

## Доказательства

- контракт сохранил допустимые поля и отбросил `name`, `phone`, `text`; недопустимые пути/события/время отклонены;
- прямой тест хранилища: 2 события, каталог `0700`, запрещённых полей нет;
- тест удаления: один старый файл статистики удалён, актуальный сохранён;
- браузер/API: `page_view`, `lead_open`, `active_time`, переход между страницами; ответы `204`;
- отчёт: без пароля `401`, с тестовым доступом `200`, 1 сессия, 3 просмотра, около минуты активного времени;
- обновлённая политика видима в браузере;
- `npm run seo:predeploy`: успешно, включая TypeScript, production build, 200 страниц и FAQ 122/122.
