# ANTI-PATTERNS.md — короткие законы из ошибок

Этот файл пополняется сразу, когда найден подход, который нельзя повторять. Не отчёт, не история, не дневник.

Формат записи:

1. Заголовок.
2. Контекст в одну строку.
3. Механизм отказа: почему именно ломается.
4. Что делать вместо этого.

Одна запись короткая: примерно до 700 знаков, максимум несколько строк. Если нужен длинный разбор, он живёт в `reports/errors-...md`, а сюда попадает только закон.

# Example: Planning From Memory

> Anti-pattern · draft

План, построенный по памяти о прошлой сессии, почти всегда пропускает решение, которое уже было записано в файлах. Перед планом читать `PASSPORT.md` и `current-steps.md`, а по затронутой области искать последние итоги в `completed-steps/`. Память чата не источник истины.
