# GLOSSARY.md — словарь проекта

Термин попадает сюда, если он используется больше чем в одном документе или больше чем в одной части кода.

| Термин | Значение | Где используется |
|---|---|---|
| Паспорт проекта | документ, отвечающий, что это за проект, зачем он и по каким границам строится | `development-docs/PASSPORT.md` |
| Шаг | единица планирования работы, дробится на подшаги и закрывается итогом | `development-steps/` |
| Подшаг | точка передачи сессии: маленький кусок работы с собственным доказательством | `development-steps/` |
| Feature report | отчёт о законченной возможности продукта, а не о конкретном шаге | `development-docs/reports/` |

## Removed

Сюда переносятся термины, которые больше не действуют, но могут воскреснуть по памяти.
