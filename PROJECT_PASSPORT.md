- TypeScript: включен strict mode.
- Публикация: Vercel.
- Текущий Vercel preview/prod URL: https://msk-maskarad-c02trzuis-mintallart-9640.vercel.app/
- Домен после публикации: `maskarad-teatr.ru`.

## 3. Важное правило по портам

Порт `3000` не использовать для этого проекта, потому что на нем может висеть другой сайт.

Зарезервированный порт проекта «Маскарад»: `4310`.

Команды:

```bash
npm run dev
```

или явно:

```bash
npm run dev:maskarad
```

Локальный адрес:

```text
http://localhost:4310
```

## 9. Дизайн-направление

Стиль: современный, теплый, театральный, семейный.

Визуальная идея:

- ощущение театральной афиши;
- бордовый как основной театральный цвет;
- золотой акцент;
- светлый фон;
- крупные CTA;
- упор на доверие родителей и простой заказ праздника.

Смысловая идея:

- не просто аниматоры;
- детский праздник как настоящий спектакль;
- театрализованные программы со сценарием;
- режиссура настоящего театрального режиссера;
- адаптация под площадку, возраст и запрос заказчика;
- отдельный сильный акцент на новогодние корпоративные праздники для детей сотрудников.
